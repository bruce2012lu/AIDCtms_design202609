# CFD 循环

## 当前算例

- 对象是单孔单元胞 UC-01b，胞尺寸 Y 2.4 mm × X 3.0 mm，不是 95×75 整板。
- 设计点口径：216 孔分 GPU 流量 1.60 L/min，单孔质量流约 1.225×10⁻⁴ kg/s。热流按 v2 的 5% 边界加在热流上，不加在流量上。
- 已收敛场以各目录 `memory/semantic/` 和结果报告为准。`lessmesh` 的 bc216：iter 421 收敛，压降 1091.51 Pa，TIM 底 342.096 K，热流 579282 W/m²。
- `uc01b_2.4x3.0lessmesh12cells` 在 2026-09-26 仍在续算。打开最新 `logs/` 再引用数字。

## 步骤

1. 读该算例 README 和最新 semantic。网格、边界、迭代数三者要来自同一次运行。
2. 改边界只改 journal 副本，并在文件名里留下孔径、孔数、热流。
3. 残差达到方案判据且质量不平衡可接受，才写结果句。
4. 和 `design/calc/model.py` 的 DP-A 对表。偏差写成偏差，不回写成“一维已被 CFD 证明”。
5. 禁止把一个单元胞的 Nu 乘孔数当成整板热阻。
6. 报告剖面云图走 `fluent-gui-capture`。期刊文件驱动 GUI，不要 HDF5 涂色，不要 `(load)` 存图。色标是该切面、该变量的 Auto Range，并关掉 Global Range。云图用 `smooth`；切面打开节点值，壁面用面值。关掉 Ground plane grid。注记只点击、不拖出引线。法向坐标用 annotation，字号 `"24"`，例如 `x=0 mm`。Z 法向截面 Y 正向朝右。不要切在 `z=-2 mm` 交界面上，铜侧第一层是 `z=-1.98 mm`。X 法向速度矢量叠在该面速度云图上，箭头等长，`skip 24`。文件名如 `x0_temperature.png`、`wall_heat_center_temperature.png`。600 步报告嵌入 png 字节。报错改过的命令写回该技能，不要重复。

CAD 轨道 `parametric-v1` 仍是 D0.50 / 128 孔。CFD 单元胞的 D0.40 方孔近似不要回写成冷板发放图。

## GPU

本机只有一张 RTX 4090，总显存 24564 MiB。2026-10-01 实测桌面已占用约 2172 MiB，空闲 21971 MiB（21.5 GB）。这张卡同时负责显示。求解把空闲显存占满时，桌面会卡住。

原生 GPU 求解器的启动参数是 `-gpu`。`-gpgpu` 只把代数多重网格卸到显卡，不能当作这个耦合共轭算例的加速，不要加。

显存估算用 ANSYS 2025-05 硬件说明里的六面体、单精度、耦合、带能量：**2.2 GB / 百万单元**。Fluent 2026 R1 手册 38.14 的 1 GB / 百万是六面体单精度带湍流的较低基准，耦合要比它高。本项目 journal 用的是 `3d`（单精度）和压力–速度耦合，按 2.2 算。双精度再乘 1.5。

手册 38.4：默认一个 CPU 进程对应一个 GPU 实例。一张卡上使用 `-t4 -gpu` 会在同一张卡里放 4 个实例。手册要求 CPU 数与专用 GPU 数一致，否则显存过载。

按空闲 21.5 GB ÷ 2.2 GB/百万：

- `-t1 -gpu`：计算上限 **970 万**单元。执行时不超过 **900 万**，给桌面留余量。
- `-t4 -gpu`（不加重映射）：上限再除以 4，是 **240 万**单元。超过这个数会卡主。
- 高于对应的线，只用 CPU，不要加 `-gpu`。
- 2026-10-01 的汇流槽网格 `hbm_d_slit_hdr.msh` 是 1223 万单元，12.2 × 2.2 = 26.8 GB，高于 21.5 GB 空闲显存。这一档不开 GPU。
