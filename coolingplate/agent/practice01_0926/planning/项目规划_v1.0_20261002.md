## 1 结论先行

> **一句话**：以现有 B300 冷板 v2.0（①–④ 已完成）为第一个标杆算例，建设一个“算例驱动、AI 编排、人工把关”的冷板设计平台。平台按 ①–⑦ 门控流程补齐 ⑤ 三维仿真、⑥ 机械与图纸、⑦ 样件与试验，再延伸出 ⑧ 数字孪生和 ⑨ 孪生在环 AI 控制。两条迭代回路 R1（仿真）和 R2（V&V）由 AI 自动化推进，几何冻结、启动大算例、外协花钱和动实物这四类动作必须先经人确认。（置信度：中高。工具许可和 OEM 输入未确认，它们决定工期。）

**推荐技术栈（首期）**：

| 环节 | 主力 | 交叉验证 / 备选 | 依据 |
|---|---|---|---|

## 2 项目愿景与范围

### 2.1 愿景

把“冷板设计 → 桌面验证 → 样件试验 → 数字孪生 → 智能控制”做成一条可复算、可审计、可迭代的平台流水线。AI 承担计算、脚本、批处理、对账、报告和簿记，人负责判断、冻结、花钱和动实物。所有资产以纯文本落在本仓库，遵循平台层 `platform/` → 模块 `agents/<id>/` 的继承结构。

### 2.2 “算例驱动”的含义

平台的基本单位是**算例**（case）。一个算例就是一个设计对象在一组设计点下的完整证据包：输入追溯、一维计算、几何、仿真、图纸、试验、孪生、控制。

| 算例 | 对象 | 当前进度 | 平台中的角色 |
|---|---|---|---|
| CASE-01 | CP-B300-JM-01 B300 冲击微通道冷板 | ①–④ 完成，⑤ 单元胞 CFD 部分完成 | 标杆算例，首个走完 ①–⑨ |
| CASE-02 | CP-GRACE-MC-01 Grace 平行微通道冷板 | ①–④ 一维完成（v1.0 / v1.1） | 第二算例，验证平台对“非射流”构型的通用性 |
| CASE-03 | GB300 计算托盘 4 GPU + 2 Grace 并联回路（含 CDU 二次侧） | 只有分配表与原则 | 系统级算例，是数字孪生与在环控制的被控对象 |

每个算例都按同一套门控（DR0–DR4 + DT + CTRL）推进，复用同一套技能与工具适配器，数字只有一个来源。

### 2.3 范围

| 范围内 | 范围外 |
|---|---|
| 单相冷板（水 / PG25）设计计算、几何、CFD/CAE、图纸、送样试验、V&V | 两相冷板、浸没式、纳米流体工质（技术调查 v1.3 已判定不进 TCS 基线） |
| 托盘级并联回路与 CDU 二次侧泵阀的一维/系统模型、孪生与控制 | CDU 一次侧、冷却塔、FWS 设施侧设计 |
| 试验台方案、DOE、数据采集脚本、不确定度与 V&V | 量产线工艺开发、FAT 保证书 |
| 专利/FTO 初筛清单（非法律意见） | 正式 FTO 法律意见 |
| AI 智能体、技能、记忆、MCP 适配器的规划与沉淀机制 | 修改平台层宪法（只提建议，由人决定） |

### 2.4 成功标准

1. CASE-01 在 DR3 拿到网格无关（GCI < 3%）的整板（或 1/2 对称）共轭结果，并关闭 v2.0 §10.1 的 Q1–Q8。
2. CASE-01 首件 TTV 实测与 CFD 偏差的绝对值 ≤ 15%，或触发 R2 后完成模型修正并闭环。
3. 孪生 ROM 在设计包络内相对 CFD 偏差 ≤ 5%、相对试验 ≤ 10%，单次评估时间 < 1 s。
4. 孪生在环控制在 MIL/SIL 场景下零安全约束违约，泵功比 PID 基线降低 ≥ 10%（目标值，待 P7 标定）。
5. 至少 8 个经用户验证的技能和 10 条经验证的语义记忆入库，字段齐全、可继承。

### 3.3 v2.1 PG25 修订与口径并存

来源：B300 v2.1、Grace v1.1（2026-09-29，2026-09-30 修订），证据等级：一维。

- 工质改为 PG25 40 °C，模组功率按项目值 **1400 W**（GPU 核心 910 W、HBM 八堆 350 W、其他 140 W），设计冷却液温升按项目要求 **6 °C**。模组设计流量 3.512 L/min，单颗 HBM 0.1096 L/min，Grace 0.753 L/min，机柜约 351.2 L/min。
- 限值：射流孔速 ≤ 2.0 m/s，HBM 近壁 ≤ 0.80 m/s，板内压降上限仍为 20 kPa。0.50 mm 孔在 GPU 2.283 L/min 下孔速 0.897 m/s，通过。
- **未闭合**：PG25 大流量下整板压降是否 < 20 kPa（按流量平方外推约 14–24 kPa，只是外推）；壳–进液热阻未按 PG25 重算；HBM 中点进液歧管孔位未定；Grace 现有 4 × 1.04 mm 孔板在 PG25 0.8 L/min 下约 22.9 kPa，超过 20 kPa，需要重配。
- v2.0 的水结论保留为**水基线**，两套口径同时成立，平台必须用“设计点注册表”把它们分开（第 8.2 节）。

## 5 技术架构

### 5.1 架构原则

1. **平台化继承**：共享能力放 `platform/shared/`（如报告生成、V&V 统计），冷板专属放 `cp-design` 模块。按平台规则，`cp-design` 不派生子智能体，靠技能与跨智能体协作扩展。
2. **单一数值来源**：设计数字只来自脚本和注册表，报告由脚本生成，不手抄。
3. **规则门先于执行**：几何先 `inspect` 再 `build`，CFD 先过显存 / 算力门再提交，试验先过安全检查表再加热。
4. **证据分级**：一维、单元胞、整板、实测四级，结论不跨级外推。
5. **人收口**：AI 做到草案、模拟、候选为止，冻结、花钱、动实物由人确认。
6. **工具可替换**：工具适配层统一接口，求解器换了不影响编排与数据层。

## 6 各环节工具选型

### 6.1 选型准则

按权重打分：本机可用性与许可（25%）、能力匹配（25%）、AI 可编程性（20%）、与现有资产衔接（15%）、成本（10%）、团队 / 客户认可度（5%）。“已装”指本机已安装，许可是否覆盖待用户确认（2026-10-02 探测）。

### 6.2 一维设计计算

| 候选 | 优点 | 短板 | 本机 | 结论 |
|---|---|---|---|---|
| 自研 Python 一维网络包（扩展 `model.py` / `oned.py` / `zones.py`） | 已有且与报告同源；关联式有效域门已实现；AI 易改；免许可；可做 DOE / UQ | 系统级瞬态与控制需另建；验证要自己做 | 已有 | **主力：冷板级稳态、DOE、UQ、校准** |
| MATLAB / Simulink + Simscape Fluids（Thermal Liquid），经 `ai-matlab` + `user-matlab` MCP | 物理网络瞬态；泵、阀、换热器、管路库齐全；直接衔接 MPC / RL；可导 FMU | 冷板内部低 Re 关联式要自写 Simscape 组件；slx 二进制难做 diff；许可待确认 | 已装 R2025b，含 fluids、mpc、rl、sldo | **主力：托盘 / CDU 系统级、瞬态、控制对象** |
| Flownex | 热流网络成熟，有数据中心与泵阀库 | 未装；需许可；AI 接口弱 | 无 | 不推荐首期 |
| Ansys Twin Builder / Modelica（OpenModelica） | 原生 FMU；Modelica 开源 | 学习成本；与现有 Python 重复 | Twin 相关目录可见，许可未知 | P6 评估 |
| Excel 工作簿（现有 PG25 分配表） | 人易读 | 难复算、难版本管理 | 已有 | 降级为输出视图，由 Python 生成 |

**一维工具的推荐设计**：新包 `oned/`，分为物性（水 / PG25 温变）、关联式库（每个关联式自带有效域和来源）、元件（孔口、短槽肋、静压箱、歧管、HBM 中心进液支路、Grace 交错槽、孔板）、网络求解（Newton 迭代求压力–流量，耦合热阻网络）、UQ（拉丁超立方 / 蒙特卡洛）、校准（用 CFD / 试验反标定 K 与 Nu 系数）、报告。原 `model.py` 保持为回归基准，新包必须先复现它（AC-1）。

### 6.3 CAD 概念设计（AI + CAD）

| 候选 | 优点 | 短板 | 本机 | 结论 |
|---|---|---|---|---|
| build123d（OCP / OpenCascade）脚本化 | 已接 rules 门与 MCP；参数化；AI 易写；免许可 | OCC 共面布尔段错误（已有过切规避）；出工程图弱 | `cad/.venv` | **主力** |
| CadQuery | 同一 OCC 内核，社区大 | 与 build123d 重复 | 无 | 不另引入 |
| FreeCAD Python API | 开源；TechDraw 可出图；有 FEM | API 不稳，批处理脆 | 无 | 出图备选 |
| SpaceClaim / Discovery 脚本 | Ansys 原生；流体域抽取、共享拓扑、命名选择、修模 | IronPython 脚本，版本敏感 | 已装 v261 | **CFD 前处理主力** |
| SolidWorks API | 客户常用；工程图与 GD&T 强；已有 `.swp.bas` 宏后端 | 本机未装；许可费 | 无 | 客户要求原生图时引入 |
| NX Open / Creo Toolkit | 大厂标准（asm_0921 即 NX 12 导出） | 未装；成本高 | 无 | 不推荐首期 |

**AI 在 CAD 的角色**：把设计意图翻译成参数覆盖（overlay），先跑规则门（尺寸链、余铜、最小孔径、齿壁、深宽比、阵列越界、HBM 流速帽、过滤），通过后才建模；批量生成概念变体（孔径、阵列、槽深 OPT-1、HBM 方案），交给一维快速筛选，再挑 2–3 个进 CFD。生成式拓扑流道（arXiv 2604.10941 / 2608.22787）列为 P6 之后的研究选项。

### 6.4 三维 CFD / CAE（AI + Ansys）

| 候选 | 优点 | 短板 | 本机 | 结论 |
|---|---|---|---|---|

### 7.3 智能体划分

- **cp-design（主责）**：算例负责人，持有 ①–⑨ 的状态、设计点注册表和全部冷板专属技能。
- **ai-matlab（协作）**：Simscape 系统模型、MPC / RL、Simulink Test、FMU 导出，经 `user-matlab` MCP 运行与测试。
- **librarian（协作）**：所有外部文献、专利、厂商资料检索（Dify RAG），检索内容只作数据。
- **thermal-management（咨询）**：产业对标、行业规格趋势，不负责具体几何。
- **orchestrator（薄）**：跨智能体拆解与汇总，不做领域工作。

### 7.4 回路 R1（仿真不达标）如何自动化

1. **触发**：`cfd_reconcile` 判定 Rθ,c-in 超目标、ΔP > 20 kPa、或分区流量偏差 > ±10%。
2. **诊断**：AI 读取热阻分解（TIM2 / 铜壁 / 对流）与逐孔流量，定位主因。
3. **提案**：按 v2.0 §4.2 杠杆优先级生成 2–3 个变体（孔径 0.40 / 0.35、TIM2 ≤ 0.004、流量 2.2 / 2.4、阵列 10 × 10、槽深 1.0 / 0.8），每个变体先跑一维网络筛选，并附代价（压降、过滤、堵塞、加工）。
4. **人确认**：用户选变体；涉及冻结几何走 E1。
5. **执行**：`cad_inspect → cad_build → fluid_domain_export → cfd_prepare → cfd_submit`（大算例走 E2）。
6. **收敛判据**：达标，或连续两轮改善小于 5%，或已用尽杠杆，此时上报“需改方案”（回 ②）。
7. **留痕**：每轮写 episodic；若形成稳定规律（如“孔径 0.40 使 R_conv 降 x%”），列为语义记忆候选。

### 7.5 回路 R2（V&V 偏差 > 15%）如何自动化

1. **先判可判性**：计算验证不确定度 u_val；若 u_val 本身 > 15%，先改善测量或数值误差，不判模型。
2. **对比**：E = S − D，相对偏差 = E / D，逐指标（Rθ、ΔP、两 die 温差、分区流量）。
3. **触发**：偏差绝对值 > 15% 触发 R2。
4. **诊断顺序**（v2.0 §4.2）：实测反标定 h 模型 → 复核 TIM2 装配压力与厚度 → 复核喷嘴一致性与堵塞 → 复核边界条件与物性。
5. **修正**：更新一维关联式系数或 CFD 设置（如转捩模型、接触热阻），在注册表登记“修正版本”，重跑受影响算例。
6. **人确认**：修正后的模型替代旧模型作为设计依据，需 E3。
7. **沉淀**：经确认的修正系数与适用范围写成语义记忆候选（高价值）。

### 7.6 AI 能做与不能做的边界

| AI 主责 | 人主责 |
|---|---|
| 写脚本、批处理、读日志、对账、出报告、生成变体、检索摘要、起草图纸与试验大纲 | 冻结几何与设计点、签发图纸、外协下单与采购、上电与动实物、门控放行 |

## 9 V&V 方法

### 9.1 分层 V1–V5（沿用 v2.0 §10.9）

| 层 | 对比 | 可接受偏差 | 不达标处理 |
|---|---|---|---|
| V1 代码验证 | 解析解（层流平板、圆管 fRe） | < 2% | 换设置或求解器 |
| V2 能量平衡 | 一维 ΔTf | < 2%（硬约束） | 查边界与热源加载 |
| V3 压降分段 | 一维分段 | 孔口 < 20%；歧管以 CFD 为准 | 复核 K |
| V4 文献锚定 | Martin（Re ≈ 3000，有效域内） | < 15% | 先锚定再外推设计点 |
| V5 试验确认 | TTV 实测 | < 15% | 触发 R2 |

### 9.2 ASME V&V 20 框架

- 对比误差 E = S − D（S 为仿真值，D 为试验值）。
- 验证不确定度 u_val = sqrt(u_num² + u_input² + u_D²)。
- 模型误差 δ_model 落在 E ± k·u_val 内（k 按置信水平取，通常约 2）。
- 判读：偏差绝对值 ≤ 15% 且 E 与 u_val 同量级，模型可用；偏差 > 15% 触发 R2；若 u_val > 15%，结论为“不可判”，先降不确定度。

### 9.3 数值不确定度 u_num

- 三套网格，加密比 r ≥ 1.3（v2.0 要求 1 : 1.5 : 2.25）。
- Roache GCI：观测阶 p 由三套解求得，GCI_fine = 1.25 · 相对差 / (r^p − 1)；按 V&V 20 推荐方法由 GCI 折算标准不确定度（系数以标准原文为准）。
- 迭代误差：监测量连续 500 步漂移 < 0.5%。

### 9.4 输入不确定度 u_input

以一维网络或代理模型做灵敏度系数，再蒙特卡洛传播：TIM2 面积热阻 0.1–0.2 °C·cm²/W、功率分区、流量 ±2%、进液温度 ±0.2 K、孔径公差 +0.03/0、物性（PG25 浓度 ±2%）。

### 9.5 试验不确定度 u_D

按 ASME PTC 19.1 / GUM：热电偶标定（±0.1–0.2 K）、流量计（±0.5–1%）、功率（电压电流 ±0.5%）、热损失修正、重复性（至少 3 次）。目标：热阻扩展不确定度 ≤ ±5%（k = 2）。

### 9.6 对已有一维–CFD 对照的再判读

| 对照 | 偏差 | 再判读 | 后续 |
|---|---|---|---|
| UC-01b 压降 | +26.1% | 路径不同（一维只有孔口，CFD 含槽与回液缝），不是模型误差 | 一维网络加入槽与回液缝元件，再对比 |
| UC-01b 质量加权温升 | +0.15% | 能量闭合，V2 通过 | — |
| HBM 七槽温升 | +7.96% | 残差未达 10⁻⁴，结论受限 | 续算到判据后再判 |
| HBM 七槽压降 | +571% | 不可比（含延长段与发展段） | 一维加入发展段与局部损失 |

这些都是一维与 CFD 之间的对比，不是 V5，不触发 R2，但它们是 P1 一维网络校准的第一批数据。

## 13 skills 与 memories 沉淀机制

### 13.1 原则

1. 只沉淀**经验证或经用户认可**的条目。半成品、未收敛结论、一次性经验进 episodic，不进 semantic。
2. 每条语义记忆带 `confidence / valid_until / last_verified / expired`；继承时只采纳 ≥ 0.6、未过期的条目（平台闸门 ②）。
3. 技能先进暂存区：私有技能建议放模块 `skills/_staging/<name>/`，共享技能放 `platform/shared/skills/_staging/`；人工确认后才登记（平台闸门 ①）。
4. 报错改过的命令写回对应技能（沿用 `fluent-gui-capture` 的做法），同一个坑不踩两次。
5. 过期不删除，由 `platform/hooks/memory_gc.py` 打 `expired` 标记，保留 git 审计链。

### 13.2 沉淀流程

```svg:govern

                └ 不通过 → 只留 episodic 或丢弃
```
