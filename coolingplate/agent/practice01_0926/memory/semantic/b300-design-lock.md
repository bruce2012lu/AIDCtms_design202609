# B300 设计锁定口径

文字当前版是设计报告 v2.0（2026-09-14）：CP-B300-JM-01 几何与工艺路径可用，热性能待证。DP-A 保证点 1100 W（Lenovo TGP），DP-B 包络 1400 W。v2 一维壳–进液热阻约 0.033–0.037 °C/W，板内压降约 3.5–5.5 kPa。GPU 区射流加短槽，HBM 区无喷嘴。两 die 合计 216 个胞。

参数化 CAD 和 `rules.py` 的对账表仍是 v1.0（2026-09-13）：128 孔、D0.50、S=3.0、H=2.0、流量 2.0 L/min（GPU 1.60 / HBM 0.40）、外形 95×75×8.5。派生量大约为孔速 1.06 m/s、Re 810、短槽 60 条、温升 7.9 K。这些是规则 INFO 的预期值，不是 v2 的结论。

材料基线 C11000/TU1。送样螺接可拆，量产真空钎焊。整板金属 3D 打印不是出货基线。

2026-09-29 单列四颗 HBM 的当前设计点是方案 D：十一条槽并联，每颗中间进水、两侧出水，工质 PG25，每颗 0.15 L/min，四颗合计 0.60 L/min。截面仍是 0.45 × 2.00 mm、肋 0.50 mm、岸 0.525 mm。槽横跨每颗芯片（沿 X），中间进流、两侧出流。进口改为静压仓。每颗 11 条 0.40×1.00 mm 中缝，仓深 4 mm（z=3–7），从列中部 y=24–26 mm 进水。2026-10-01 核对：缝速 0.57 m/s，缝压降约 0.30 kPa。网格 mesh/hbm_d_slit_lt9m.msh（861 万）。汇流槽只保留流体，槽周的铜不进网格，以便单进程 GPU。沿 Y 的 863 万网格 mesh/hbm_d_lt10m.msh 方向不对，已停。同日较早的方案 C 仍是水、0.20 L/min 的记录。上面 v1.0 规则里的整板 HBM 0.40 L/min 没有被这条单列口径改写。
