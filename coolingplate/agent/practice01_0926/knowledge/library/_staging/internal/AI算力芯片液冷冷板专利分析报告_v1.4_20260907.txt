0. 结论先行
一句话：
铲齿守量产，微通道 / MLCP 是 2 kW 级主路径，射流补热点，金刚石做均热，纳米流体不宜当主产品。最有价值的窗口不在“再挖一条直通道”，而在分区 / 拓扑流道、射流–微通道杂交、去 TIM2 盖板一体化、金刚石嵌件与可制造防堵防漏工艺。
冷板式液冷已是未来 3–5 年 AI 服务器的主流散热形态。
欧洲专利库 2000–2023 年数据中心冷却专利显示，2015 年后液冷申请占比持续上升，近期时段液冷可占相关专利约八成，其中直接液冷（冷板）是主体。
五条技术路线并不并列竞争，而是分层叠加
（见下表与第 3 章）。
国内外分工已经出现：
美欧日掌握基础结构与封装级微射流 / 微通道；台湾厂商卡位 NVIDIA MLCP / MCL 认证产线；大陆在系统级液冷（浪潮、曙光数创、英维克、华为）专利密度高，但
微米级蚀刻 + 真空扩散焊 + 半导体级洁净
仍是短板。
工艺必须分三条产线写，不要混成一个车间指标：
机加工（铲齿 / CNC / 微钻）+ 真空钎焊或隧道炉保 B300 量产；蚀刻 + 扩散焊做 MLCP；金属 3D 打印做异形喷嘴、MMC 与拓扑样件。铜增材的粉末残留、粗糙度和导热折损仍是课题，量产件应走“机加底板 + 增材/蚀刻盖板”的混合工艺（第 3.7 节）。

原理详解
微翅片走的是
扩展表面
：单位投影面积上的对流面积 = 底板 + 两侧肋壁。肋效率取决于肋高、肋厚和铜热导。铲齿（skiving / MDT）与铣削的本质差别是
不切除材料、肋根无焊缝
，底板导热路径连续，比“底板 + 焊接翅片”更接近铜的体材料极限。
流动上，直肋通道仍是平行层流占多数：入口边界层薄、沿程逐渐变厚，出口侧换热变差，这就是“沿程温升 + 热点不在几何中心”时铲齿容易失守的原因。加密节距能降热阻，但流阻近似随间隙缩小而急升。针肋 / 斜切成针（US9795057）用周期性分离破坏边界层，对非均匀热流更友好，加工和清洗更难。
对规格的含义：铲齿是当前 
R
θ

3.6.3 推荐专利方案 A（首选）：GPU / HBM 双物理杂交冷板
方案 A 是本报告建议的新权利要求结构，调研文献没有“GPU 射流 / HBM 禁射流 + 隔离肋”的现成原图，故用自绘。分区必要性见第 2.4.0 节 GB200 热图原图。
图 3-7 · 自绘示意
（无对应原图）。GPU 区：密射流 + 短微通道 + 局部抽吸，对准 SM 热点。HBM 区：只走低速平行微通道，限制近壁流速，避免冲蚀与机械疲劳。中间隔离肋切断高速射流对 HBM 的串流，并提供结构刚度。
要解决的矛盾
AI 加速器不是均匀热源。GPU 逻辑区热流高、允许较高对流剪切；HBM 热流较低但结温更敏感、焊球与堆叠怕冲蚀和压装偏载。华为 WO2026103052A1 已写“按热密度用不同结构”，但没有把
HBM 最大近壁速度、射流不得覆盖 HBM、隔离肋的力学功能
写成必要技术特征。浪潮太阳花针对小面积 CPU，不是 chiplet 双区。
独立权利要求建议（结构，草案）
一种液冷冷板，包括进液腔、出液腔和换热底板；换热底板在投影上划分为第一区（对应逻辑裸片）和第二区（对应高带宽存储器）。
第一区设喷嘴阵列与水力直径 D1、流程 L1 的短微通道，喷嘴将冷却液冲击第一区底壁后经短微通道进入出液腔；喷嘴密度随该区热流图单调增加。
第二区仅设水力直径 D2 > D1、近壁设计流速低于预定上限 V2 的微通道，
不设置射流喷嘴
。
第一区与第二区之间设隔离肋，隔离肋同时构成流道隔墙和抗弯加强筋，使第二区冷却液不与第一区射流滞止区直接连通。
冷板在额定流量下总压降 ≤20 kPa（或项目 OEM 点）。
从属权项：局部抽吸孔仅布置在第一区；第二区通道沿 HBM 长边均流；隔离肋与封装加强环对位；可做成独立冷板或 MLCP 盖板。
规避要点：
不要只写“分区用射流和微通道”（华为）；必须写 HBM 无喷嘴 + 流速上限 + 隔离肋的力学/流动双重功能 + 压降窗。
3.6.4 推荐专利方案 B：可更换喷嘴芯 + 在架反冲洗杂交冷板
图 3-8 · 自绘示意
（无对应原图）。微通道底板固定在 GPU 上不拆；喷嘴芯从上方拆换。实线青箭头为正洗：进液 → 喷嘴射流 → 短通道 → 出液。虚线橙箭头为反洗：出液侧倒灌，经通道和喷嘴反向喷出，颗粒进进液侧颗粒阱。跨喷嘴芯的 ΔP 超限则报警反洗或换芯。
图怎么读
方案 B 不改换热物理（仍是射流 + 短微通道），改的是
可维护性
：堵点在喷嘴芯，芯可在架更换；底板不清空、GPU 不拆。浪潮斜板是几何防堵，本方案是运维防堵。正洗口 / 反洗口、颗粒阱、压差阈值必须写进权项，否则只剩“可拆孔板”，空间很窄。
要解决的矛盾
杂交最怕堵：喷嘴堵则热点失守，微通道堵则整板报废。浪潮上下腔斜板宣传防堵，但是
几何防堵
。数据中心要的是 5–10 年可维护：不拆 GPU 也能反冲、换喷嘴板、抓住颗粒。这是工艺 + 运维方法专利，国内相对空。
独立权利要求建议（装置 + 方法，草案）
冷板包括固定于服务器的微通道底板，以及可拆卸密封的喷嘴芯（孔板），喷嘴芯将进液分成射流束冲击底板后进入微通道。
进液和出液各设正洗口与反洗口；反洗时冷却液从出液侧进入微通道，经喷嘴反向喷出，将颗粒带入设于进液腔下游的可更换颗粒阱。
压差传感器跨接喷嘴芯两侧；压差超过阈值时发出反洗或更换喷嘴芯的信号。
方法权：服务器在架、冷板不与芯片分离的条件下完成反洗或更换喷嘴芯。
规避要点：
不与浪潮斜板“防堵几何”抢形态；强调可更换芯、颗粒阱、压差阈值、在架操作。结构、方法、检测分三件申请。

要解决的矛盾
MLCP 取消 TIM2 之后，热点仍在盖板内侧。整板铺 CVD 金刚石太贵，也会撞上 Element Six 铬键合家族。把
小面积金刚石嵌币
只放在射流滞止点正下方（例如占盖板投影 <15%），外围仍是铜短微通道，界面走梯度碳化物或玻璃相而不是铬独立层。
独立权利要求建议（草案）
一种微通道盖板，盖板内含喷嘴和流程 ≤8 mm 的短微通道，冷却液在盖板内完成冲击与排出，盖板与芯片之间不设置独立 TIM2 层。
在预定热点投影处嵌装导热嵌件，嵌件平面面积之和小于盖板换热面的 15%，嵌件热导率高于铜，且与铜基体通过非铬主导的梯度界面结合。
每一嵌件中心与至少一喷嘴轴线对位，对位偏差小于预定值（如 0.2 mm）。
盖板采用蚀刻 + 真空扩散焊 + 镀层，并含翘曲补偿柔性环或双件盖结构。
规避要点：
避开“金刚石 + 铬直接键合 + ≥1 kW/cm²”（E6）；避开 Intel DLMJ 的“微通道上方整层垂直歧管”独立权项表述；用面积比、对位、非铬界面、去 TIM2、扩散焊工艺把方案收窄到可授权。

3.7.6 对专利与产线的含义
权利要求应带
可制造约束
：最小水力直径、钎料禁入区、可冲洗死区、接触面平面度、压降 ≤20 kPa。只写拓扑形状、不写怎么做出来，审查和量产都会被打回。
增材相关申请优先写：
去粉通道与反冲洗
（与方案 B 捆绑）、打印态粗糙度分区（对流面保留、密封面机加）、铜合金热处理恢复导热。不要只写“3D 打印微通道”。
生成式流道（arXiv 两篇）是设计方法，不是传热机制；专利应写“生成结果向机加 / 蚀刻特征投影”的约束算法，否则无法量产，也难与现有拓扑优化专利区分。
大陆相对台湾的缺口仍是
蚀刻 + 真空扩散焊 + 半导体洁净
，不是缺一台 SLM。买增材设备补不了 MLCP 认证。
