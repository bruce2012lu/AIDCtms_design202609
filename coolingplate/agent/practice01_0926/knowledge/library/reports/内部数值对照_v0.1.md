# 内部报告数值对照 v0.1（外部来源支持 / 存疑）

日期：2026-10-02。对照对象：B300 设计报告 v2.0（2026-09-14）、v2.1 PG25（2026-09-29）、Grace v1.0/v1.1、Grace 边界摘录、cycle-20260926、UC-01b CFD 语义记忆。内部文件均未修改。

判定口径：
- **支持**：外部 L1–L3 原文（本库已核对页码）与内部值一致。
- **部分支持**：外部来源存在，但口径、产品、条件不同，或只有 L4/二手。
- **存疑**：外部来源与内部值不一致，或内部值的依据本身是假设且影响结论。
- **无外部来源**：项目自定或估算，内部报告已如实标注时不算错误，但不能当外部事实引用。

每行最后一列是 `registry/citations.json` 的引用编号。

## 7 要点

被外部权威来源支持的：1400 W 包络、Lenovo 的 1100 W 口径、135/155 kW 与 90 % 液冷、表 27 流量–压降、工质选择、Grace 300 W 含内存、OCP 温升带与比流量、TIM2 0.1–0.2 °C·cm²/W、水物性、铜导热率、Martin 不适用、过滤 1/10 规则。

存疑、会影响结论的（按影响排序）：
1. **PG25 物性**（粘度偏低 17–27 %），直接改变 Re、Pr、压降和 h。
2. **壳–进液热阻 0.033–0.037 °C/W** 缺外部验证；平板射流关联式给出的对流项约为内部值的 2.5 倍，差距全靠短槽面积放大。
3. **Tj,max 90 °C 与 R_pkg 0.008–0.012 °C/W** 无出处，而热阻目标由它们推出。
4. **孔速上限 2.0 m/s** 比 CDA 与 OCP 参照宽，D0.40 方案在上沿已超参照。
5. **孔口 K = 1.8**、**UQD 4–8 kPa**、**20 kPa 上限** 无出处。
6. **UC-01b 只有单套收敛网格**，不能报告离散不确定度。

建议闭合顺序：先拿 PG25 物性结论（并行任务）→ UC-01b 补两套网格跑 `tools/gci.py` → 获取 Rattner 2017 与 Li & Garimella 2001 → 单孔流阻与 TTV 试验（⑦）。
