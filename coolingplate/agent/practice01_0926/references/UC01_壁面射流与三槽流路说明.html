壁面射流是什么，水在 UC-01b 里怎么走

用本设计的「一孔 + 三短槽 + 两端回液缝」把冲击三区说清楚：自由射流打到铜壁之后转 90°，贴着壁面刮过去的那一层才叫壁面射流。侧槽并不对着孔，但仍能换热，主要就是靠它。

UC-01b 带槽流体S = 3.0 mmD = 0.40 mm（代码默认 0.50）H = 2.0 · 盖板 t = 2.5三槽 0.40×1.50 · 节距 0.80回液缝 0.80 · 上抽

一句话：孔里射下来的是自由射流；正对孔、打在壁上的是驻点；转过弯、贴着铜壁往外刮的薄高速层才是壁面射流。它不是槽底深处的导管流，也不是还没撞壁的那股竖直流。

什么是壁面射流

冲击射流打到固体壁上之后，会依次经过三个区（Martin 1977；Hussain 等论文里的 free-jet / stagnation / wall-jet）：

  • ① 自由射流——还在孔口和铜壁之间，方向朝下。本格 H = 2.0 mm，用 ⌀0.40 时 H/D = 5.0（代码默认 ⌀0.50 则为 4.0）。
  • ② 驻点——射流轴打到壁面，动量从轴向变成径向，边界层被压到最薄，局部换热系数 h 最高。UC-01b 里只有中槽正对这个核。
  • ③ 壁面射流——流体已经转过 90°，变成贴壁的薄剪切层，沿径向 / 沿 ±X 往外跑。侧槽就处在这层扫过的路上。
不是壁面射流的两样东西：（1）孔里射下来、还没撞壁的竖直射流；（2）已经掉进 1.50 mm 深槽、按矩形管流往前走的那部分。壁面射流指的是贴着肋顶 / 槽口附近壁面的那一层。侧槽虽然不在孔正下方，仍能看到大约驻点 0.4–0.7 的 h，原因就是这层壁面射流还扫得到 Y = ±0.80 mm（约 r/D = 2）。

流体怎么走（四个方向）

路径固定为：孔口自由射流 → 底面驻点 → 壁面射流沿径向 / ±X → 扫入侧槽并沿间隙走 → ±X 端回液缝向上抽走。必须尽快抽走，否则壁面射流会变成交叉流，把下一孔的驻点吹歪。
