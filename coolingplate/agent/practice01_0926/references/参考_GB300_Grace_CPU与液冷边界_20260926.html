1. 本项目要冷却的是哪一颗 Grace

计算托盘上是 两颗独立的 Grace，各带自己的 LPDDR5X，各需要一块冷板。这不是 Grace CPU Superchip（一模块两颗 Grace、整模块约 500 W）。

事实出处设计里怎么用
GB300 NVL72：72 颗 Blackwell Ultra GPU + 36 颗 Grace CPUNVIDIA GB300 NVL72 产品页整柜数量。本冷板只对一颗 Grace。
Lenovo 计算托盘：两颗 Grace，每颗 72 个 Arm Neoverse V2 核，基频最高 3.1 GHz，TDP 300 W，含内存功耗Lenovo Press，LP2357采用 单板热设计点 300 W，内存不再另加。
每颗处理器最高 480 GB LPDDR5X ECC，固定配置下托盘 960 GB，即每颗 480 GB；单 CPU 峰值带宽最高 384 GB/s；内存 4266 MHzLenovo Press，LP2357采用 冷板必须盖住 CPU 和板载内存。
Grace 以 BGA 焊在 HPM 上。换 CPU 就是换整块模组。Lenovo Press，LP2357冷板是可拆的直触件，不做成封装内冷板。
每块 HPM 含一颗 Grace，并与两颗 GPU 以 NVLink 相连（Lenovo 写法：到两颗 GPU 各 450 GB/s 双向；处理器之间 NVLink-C2C 300 GB/s 双向）Lenovo Press，LP2357与托盘照片一致：一块 NVL2 = 1 Grace + 2 B300。冷板按这个拓扑放。
液冷冷板接触 GPU、CPU 和内存。工质可选去离子水或 PG25。CX-8 与 NVSwitch 另有冷板。Lenovo Press，LP2357本冷板只覆盖一颗 Grace 及其 LPDDR5X。回路过滤跟着 GPU 射流孔走。

Grace C1 可配置到约 140–250 W 档单路 Grace C1 的产品档Lenovo GB300 写的是 300 W，且含内存。以托盘规格为准。
LPDDR5X 子系统大约 16 WNVIDIA Grace Performance Tuning Guide：用来对比传统 DDR 的内存功耗量级这是带宽能效宣传口径，不是 GB300 480 GB 配置的热设计分工。设计报告把内存区按 40 W 留裕量，总功率仍锁在 300 W。
B300 冷板 95 × 75 mm、128 孔、2.0 L/min、1100 W本项目 GPU 冷板热流、封装和流阻都不在一个量级。Grace 冷板单独编号 CP-GRACE-MC-01。
公开资料没有的东西：Grace 裸片外形、盖板图、螺孔、LPDDR5X 颗粒排布、CPU 与内存的官方功率地图、结温上限、冷板允许堆高。设计报告里的平面尺寸都标成候选，等模组盖板图替换。来源页没有给出这些图。
