  2. 射流冲击是下一档强化换热的主候选。射流破坏驻点边界层，局部换热可明显高于平行微通道。Wiwynn 白皮书：射流冷板热阻相对传统冷板下降 20–48%，与封装内集成冷板叠加可达 53%。短板是均温性（冷斑）、交叉流、喷嘴加工与对中。

  4. 纳米流体实验室增益明确，TCS 近期不宜作为基线工质。综述普遍报告 10–40% 换热增强，但团聚、沉降、堵塞、电导率与 OCP 水基规范冲突，更适合一次侧/板换试点。
  5. 规格必须分层写。芯片热阻、冷板压降、机柜 OEM 流量–温度表、TCS 水质、FWS 的 ASHRAE W 类是五张表。禁止用固定 10 K 温升反推流量；禁止把 W32 设施水写成机柜进液。

要点不是“总功率变大”，而是四件事同时发生：

  1. 热流空间非均匀。GB300 托盘是多 GPU + Grace + HBM；Rubin 是双计算 die。平行直通道按均匀热流优化会在热点失守。

  3. 串联界面热阻成为主瓶颈。硅 → TIM1 → 盖板 → TIM2 → 冷板铜壁 → 对流。
  4. 机柜水力被 OEM 表锁死。GB300 入口 25–45 °C 对应 59–177 L/min，冷板不能靠无限加流量救命。

3. 冷却技术规格要求

规格必须按芯片 / 冷板 / 模组 / 机柜 / 工质五层写。行业真正在收紧的，是单位面积换热能力（热流密度 q″）和结–进液热阻 Rθ两条曲线，而不是“能不能上液冷”。

为什么热阻会随功率“被迫”下降

结温上限几乎不动（多数 GPU 持续满血仍按 Tj ≤ 83–90 °C），进液温度还在往暖水走（25–45 °C）。可用温差 ΔT = Tj − Tin 被压缩到约 40–60 K，于是：

Rθ ≤ ΔT / TDP。按英伟达最新功率、50 K 预算：B300 TGP 1 100 W → 上限 0.045；NVL72 报道 1 400 W → 0.036；Rubin 1 800 / 2 300 W → 0.028 / 0.022。再留 TIM、扩散和流量不均，工程目标落到 B300 <0.025–0.030、Rubin <0.018–0.022。这不是口号，是结温与暖水进液夹出来的。

5. 核心技术方向：优势、短板与工艺要求

5.1 微通道冷板（Microchannel）

原理说明。Tuckerman–Pease（1981）把冷却从“一块铜上开几条大沟”改成“亚毫米密排通道”：水力直径 Dh 缩小后，同样层流 Nu 几乎不变，但 h = Nu·kf/Dh 上升，同时润湿面积 Awet 增加，对流热阻 1/(hA) 下降。GPU 冷板通道宽/高约 0.2–1.0 mm，Re 多数 < 2000，换热靠薄通道 + 铜肋把底板热导到两侧壁，不是靠把水打成湍流。

热量沿一条串联路径走：硅 → TIM → 铜底板扩散 → 肋导热 → 槽壁对流 → 流体焓升。OEM 把单卡流量锁在约 1–3 L/min 后，焓升项 1/(ṁcp) 几乎不能再降，设计师只能动 h 和 Awet。平行长通道的结构性失败是：入口段热边界层薄、换热好；下游边界层变厚，流体又已被加热，B300/Rubin 的后半段和出口侧 GPU 往往先超温。

5.1 控制方程（Tuckerman–Pease / 层流微通道）

矩形槽：宽 w、高 a、长 L、肋厚 t。工质按水或 PG25 的物性取值。

Dh = 2wa / (w+a)　　Re = ρu Dh / μ　　Nu = h Dh / kf

层流充分发展：Nu ≈ 3.7–4.4（圆管）或按宽高比取常数　　⇒　　h = Nu·kf / Dh

Rconv = 1 / (h Awet)　　Awet ≈ n·2(w+a)L　　ΔTbulk = P / (ṁ cp)

ΔP = f (L/Dh) (ρu²/2)　　层流 f ≈ 64/Re（圆）或 96/Re（平行板）　　Rθ ≈ RTIM+Rsp+Rwall+Rconv+1/(ṁcp)

原理要点

  1. 把“厚边界层”切薄。水力直径 Dh 缩小后，层流充分发展的 Nu 仍大约是常数（圆管约 3.7–4.4），但 h = Nu·kf/Dh，所以 Dh 减半，h 约翻倍。
  2. 肋是导热翅，不是装饰。铜肋把底板热量送到两侧壁，相当于把一块 footprint 展开成几倍润湿面积。肋太薄则导热不足，太厚则流体侧面积不够。
  3. 焓升与对流要分开算。即使壁面 h 很高，流量不够时出口水温照样抬高整板。OEM 锁死流量后，只能靠结构，不能靠“再加点水”。
  4. 长通道失效。入口段热边界层薄、换热好；下游边界层变厚，再叠加流体已被加热，后半段芯片往往是热点。
优势
  • 工艺与供应链成熟：CNC / 蚀刻 / 铲齿 + 盖板真空钎焊，已服务 H100/H200/B200。
  • 热阻可做到工程可用的 0.02–0.04 °C/W 量级（视流量和 TIM）。
  • 与现行 DI 水 / PG25、UQD、盲插歧管完全兼容。
  • 结构刚度和密封路径清晰，氦检、保压、盐雾等可靠性体系现成。
短板
  • 沿程热边界层持续增厚，通道后半段换热变差；大面积 Chiplet 上进出口温差和横向温差同时恶化。
  • 压降随水力直径四次方敏感。通道再窄，泵功和堵塞风险一起上升。
  • 流量分配不均：入口效应、公差、局部堵塞会造成“有的沟过热、有的沟空转”。
  • 对水质和过滤极敏感；层流下对热点的主动冲刷弱。

5.2 微翅片 / 铲齿 / 针翅（Micro-fin, Skived Fin, Pin-fin）

原理说明。微翅片和微通道是同一套能量方程的两种几何：都是“把 footprint 展开成更大的润湿面积”。差别在工艺和流场。铲齿把整块铜的皮立起来，底板与翅是连续铜，翅根没有钎缝热阻；盖板再钎上，形成封闭缝。针翅（圆柱或方柱错排）让流体在每个针后分离、再附着，局部 h 高于平行缝，单位体积面积可为平行微通道的 2–3 倍。

翅不是越密越好。翅效率 ηf = tanh(mH)/(mH)：翅太高太薄时，顶端已经接近流体温度，多出来的面积几乎不换热。翅距小到与 25 μm 滤芯漏过的颗粒、汽泡同量级时，堵塞和压降先于换热到达极限。B300 正确做法是按 GPU 核 / HBM 分区变翅距，而不是整板最密。

5.2 控制方程（扩展表面 / 翅效率）

直肋近似：高 H、厚 t、导热 k、表面换热 h。针翅把 t 换成当量直径，并计入尾迹再附着。

m = √(2h / (k t))　　ηf = tanh(mH) / (mH)

Atot = Abase + ηf N Afin　　Q = h Atot (Tw − Tf)

铲齿：Rroot = 0　　焊接翅：Rroot ≈ δbraze / (kbraze Aroot)（常 10–50 μm 异质层）

PEC = (Nu/Nu0) / (f/f0)1/3　　密翅若 PEC<1，就是“面积加了、综合变差”

量工程读法

ηf < 0.6翅太高/太薄，先减 H 或加厚，不要再加密
Rroot=0这是铲齿成为 SXM 事实工艺的核心，不是“看起来像微通道”

原理要点

  1. 消灭翅根界面。焊接或粘接翅片会在翅根引入 10–50 μm 异质层。铲齿是同一块铜，这一项热阻为零——这是它成为 SXM 冷板事实工艺的核心原因。
  2. 扩展表面效率。翅高、翅厚、翅距决定“面积增加”和“翅端温度是否跟得上底板”。翅太高而太薄，顶端几乎不换热。
  3. 针翅比平行翅更扰流。每个针后形成尾迹和再附着，局部 h 高于平行缝；文献中歧管针翅单位体积面积可为平行微通道的 2–3 倍。
  4. 密不等于优。翅距小到与颗粒、气泡同量级时，堵塞和压降先于换热到达极限。要用热图做分区变翅距，而不是整板最密。
优势
  • 铲齿翅根无界面热阻，比“底板+焊接翅片”更接近材料极限。
  • 单位体积换热面积高；针翅可比平行微通道高约 2–3 倍（中）。
  • 模具费低，改翅距/翅厚快，适合 GPU 冷板多品种、短周期。
  • 与射流天然互补；文献中针翅板比平板换热约高 34.5%。
  • 铜铲齿是当前 NVIDIA 类 SXM 冷板的事实工艺标准之一。
短板
  • 薄翅易倒、易伤，搬运和扣盖对位要求高。
  • 高密度翅束把流道变成窄缝，压降和堵塞风险接近微通道。
  • 铲齿翅形受刀具运动约束，三维歧管、变截面不如增材自由。
  • 针翅 CNC 成本高；增材则导热和表面质量打折。
  • 单纯加密翅片可能出现“面积增加了、面积平均 Nu 反而下降”。

适用窗。与微通道重叠，但更偏量产 GPU 冷板。需要局部强化时，用变翅距或针翅分区，而不是整板统一最密翅。

5.3 冲击射流（Jet Impingement）

原理说明（Barewar / Hussain）。一股射流从喷嘴射出后分成三段：自由射流（势核 + 卷吸）、驻点区、壁面射流。驻点处轴向动量转为径向，静压升高，速度边界层和热边界层都被压到最薄，局部 Nu 最高，单相 h 可到 2–8×10⁴ W/(m²·K)。离开驻点 1–2 个孔径后 Nu 近似指数衰减，靶面出现“钟形”和冷斑网格。

多孔阵列不能只抄单孔公式。孔间距 S/D、喷距 H/D、废液交叉流三者联立：上游射流的废液横向吹过下游孔，把射流吹歪、驻点漂移，峰值 Nu 崩塌。1U 冷板必须做静压箱 + 分区回流（或上抽下喷）。液冷最佳 H/D 常见 2–6：太近展不开，太远势核耗尽。B300/Rubin 的用法是把驻点对准 GPU 核和 HBM，而不是整板均匀打孔。

原理要点

  1. 驻点减薄边界层。轴向动量在壁面转为径向，驻点处速度边界层和热边界层都极薄，单相 h 可到 2–8×10⁴ W/(m²·K)，这是它比平行微通道“狠”的原因。
  2. 钟形 Nu。离开驻点约 1–2 个孔径后 Nu 迅速下降，靶面出现冷斑网格。要用孔间距、叉排、旋流孔或靶面针翅把冷斑抹平。
  3. 交叉流是第一敌人。上游射流的废液横向吹过下游孔，把射流吹歪、驻点漂移。1U 冷板必须做静压箱 + 分区回流，或上抽下喷。
  4. H/D 有最佳窗。太近：射流展不开、加工公差敏感；太远：势核耗尽，到达壁面时核心速度已经衰减。液冷常见 2–6。
  5. 与微通道耦合优于纯射流平板。上射流负责打破边界层，下针翅/微通道负责扩面积和导流，PEC 通常更好。
优势
  • 单相方案里驻点局部换热系数最高的一类；适合砸在 GPU 热点、HBM 邻区、Chiplet 缝。
  • 流程短，不像长微通道那样“后半段失效”。
  • Wiwynn（2025）：热阻相对传统冷板降 20–48%；再叠加封装内流道，最高约 53%。
  • 可用 PEC = (Nu/Nu0)/(f/f0)1/3 做热–阻权衡。
  • 两相射流可在很低流量下吃掉千瓦级负荷（约 0.3 L/min 冷却 1 000 W，中）。
  • 增材制造打开异形孔、收敛孔、旋流孔设计空间。
短板
  • 均温性差。圆孔阵列留下冷斑网格，热应力和封装翘曲风险上升。
  • 交叉流。1U 限制空间里废液排不走，下游射流失效。
  • 喷嘴堵塞：孔直径常 0.3–1.0 mm，对颗粒更敏感。

  • 冲击载荷与空化；至少三层结构，密封面更多。

5.4 金刚石（均热器 / 金刚石微通道）

原理说明。金刚石不替代对流。它降低的是扩散热阻 Rspread：热点特征尺寸越小，热越走不出去，越需要高 k 的均热器。室温热导率约 900–2 350 W/(m·K)（多晶到单晶），铜约 400，硅约 148。Element Six 把约 400 μm Diafilm 接到硅测试芯片与硅基微射流/微通道之间，总功率 10→70 W 时热点温降从 4 °C 增到 45 °C——功率越高，摊热收益越大。

界面热阻（TBR）是方程里真正的变量。体导热优势可以轻易被 1 μm 空洞或厚焊料吃光。实验室 Si–单晶金刚石表面活化键合 TBR ≈ 9.5 m²·K/GW 已不再是数量级瓶颈；量产金属化、AMB、空洞仍可能差两个数量级。所以近中期产品是热点面积的金属化 CVD 片 + 低温键合 + 铜冷板，不是第一步开金刚石微通道。Rubin 双 die 尤其需要两片或一片盖住两个热点的摊热，而不是整板铺金刚石。

5.4 控制方程（扩散热阻 + 界面 TBR）

q″avg = P / Aspread　　Aspread 越大、k 越高，冷板对流负荷越接近封装平均

RTBR = TBR / A　　Rθ = RSi + RTBR + Rspread + Rcoldplate

kdiamond / kCu ≈ 2–6　　若 TBR 差两个数量级，这项比把铜改成金刚石更致命

原理要点

  1. 扩散热阻与导热系数成反比。热点特征尺寸越小，越需要高 k 的均热器。铜 400、Si 148、金刚石 900–2350 W/(m·K)，这是材料位差，结构优化补不回来。
  2. 各向同性。石墨/石墨烯面内很高、法向很差；金刚石三个方向都能导，适合从硅背面把热既向上也向外抽。
  3. 界面才是方程里的变量。实验室 Si–SCD 表面活化键合 TBR ≈ 9.5 m²·K/GW 已不再是数量级瓶颈；量产金属化、空洞、焊料层仍可能把 TBR 做差两个数量级。
  4. 电绝缘 + 低 CTE。近结区可以少一层绝缘膜，并减轻与 Si/GaN 的热失配。和铜接头、钢快接的失配要单独做可靠性。

密歇根州立大学综述将“金刚石微通道热沉”定义为材料与微通道的合体：模拟上 1 000 W/cm² 时单晶金刚石微通道热阻约 0.22 K/W，较同尺寸硅基降 80% 以上；文献甚至报道局部 >10 000 W/cm² 的极端能力。这是材料上限，不是 GPU 冷板量产数。

优势
  • 摊热点能力是铜、Si、AlN 都换不来的；对 Chiplet / 3D 堆叠局部热点几乎刚需。
  • 电绝缘，近结区集成时少一层绝缘膜。
  • CTE 低，与 Si/GaN 比铜更匹配。
  • 化学稳定、耐辐照；可与射流、微通道、两相叠加。

5.5 纳米流体（Nanofluids）

原理说明。纳米流体改的是流体物性，不是流道几何。金属/氧化物/碳颗粒（Al₂O₃、TiO₂、Cu、MWCNT、石墨烯）分散进水或乙二醇后，有效导热 keff 上升，颗粒还可能扰动边界层，实验室 Nu 常见 +10–40%。它不增加润湿面积，也不摊热点，所以单独无法把 0.03 °C/W 打到 0.02——TIM 和扩散项动不了。

浓度有峰值。Maxwell–Garnett 型公式里 keff 随体积分数 φ 升，但粘度升得更快，泵功和沉降一起恶化。Hussain 2021 引用的 SiO₂–水：H/D=2–5、0–6 vol% 时，约 2.8%、喷距 5 mm 最好，6% 反而无效。进入 0.2 mm 微通道和 0.3 mm 喷嘴后，团聚体尺度与通道同量级，25 μm 过滤要么滤掉“有效颗粒”，要么被堵死。OCP 水基规范没有纳米颗粒这一栏。因此：一次侧/板换可以试点，GPU 二次侧 TCS 否决。

  1. 有效介质，不是新流道。纳米流体把固体高导热“借”给液体，keff 上升；同时颗粒扰动边界层。它不增加润湿面积，也不摊热点。
  2. 浓度有峰值。过稀增益不够；过浓粘度、沉降和团聚同时恶化。Hussain 综述中 2.8% 优于 6%，是典型的 PEC 拐点。
  3. 稳定性由 DLVO 力平衡决定。范德华吸引压过静电排斥就团聚。热循环、剪切、离子污染都会破坏 zeta 电位。
  4. 系统级经常不合算。即使 Nu 升 20%，泵功也升；再叠加污垢，长期 Rθ 可能比纯水差。OCP TCS 规范没有纳米颗粒这一栏。
优势
  • 实验室单相换热增强常见 10–40%。
  • 不改冷板模具即可做“流体侧”增益。
  • 石墨烯功能化纳米流体在一次侧/CDU 板换试点中，逼近温差下降约 0.3–1.7 K（中）。
  • NEPCM 浆料可把潜热带进单相回路，缓冲负荷阶跃。
短板（数据中心综述共识）
  • 长期稳定性。团聚、沉降；zeta 电位需长期 >30 mV。
  • 微通道/射流孔堵塞与污垢热阻：沉积后增益变负。
  • 磨损、腐蚀、电导率上升，与漏电/腐蚀监测冲突。
  • 与 OCP 规范冲突：纳米颗粒不在合格冷却液成分表里。
  • 过滤悖论：25 μm 滤芯会滤掉“有效颗粒”，或被它们堵死。
  • 粘度上升 → 泵功上升，PEC 经常接近 1。

5.6 必须同时看的相邻技术

原理说明 · 歧管微通道（MMC）。平行微通道的压降和后半段失效都来自流程太长：ΔP ∝ L/Dh⁴，出口焓升 ∝ L。MMC 不改对流机制，把一条长沟切成 N 条短沟：上层歧管均分流量，下层微通道或针翅只负责局部换热，废液从另一层抽走。流程长度降为 L/N，压降和均温同时改善，两相也不容易在长槽里提前干涸。B300 量产仍可用强化铲齿；往 Rubin 1.8–2.3 kW 走时，MMC 是单相结构吃干的下一步，优先级高于纳米流体。

5.7 微通道融合冲击射流：是否存在、怎么融合、能不能上 AI 冷板

结论：存在，而且已是独立技术路线，不是实验室偶发结构。从 Sung & Mudawar（2008）的“微射流喂入微通道”，到北京大学宋柏团队 Nature Electronics（2025）的“歧管–微射流–锯齿微通道”做到 3000 W/cm²，再到纬颖（Wiwynn）把射流冷板与封装内流道叠到热阻降 53%，耦合的目的都一样：用射流打破边界层，用微通道扩面积、导走废液、抹平冷斑。

原理说明。单独微通道的 h 受层流充分发展限制，单独射流的 Nu 离开驻点就塌、废液变成交叉流。耦合把两者写成并联：驻点正下方用射流项 hjAstag，周围壁面用通道项 hchAwall，再用独立回流槽把 Gc 抽走。Sung & Mudawar 的关键判据是射流速度要够、槽要够浅，射流才能穿过槽内平行流打到加热壁；槽太深，射流被主流托住，退化成普通微通道。Hou（2022）用约 100 孔/cm² + 进出隔离，在 210 mm² 上做到 400 W/cm²、Rθ 0.11 K/W、ΔP 13.5 kPa——压降仍落在 GPU 冷板常见窗内。

5.7.4 耦合能成立的流体机理

  1. 射流穿透槽内主流。Sung & Mudawar：射流速度够、槽够浅时，射流能穿过槽内平行流打到加热壁，壁温明显下降。槽太深，射流被主流“托住”，退化成普通微通道。
  2. 进、出必须物理隔离。Hou：密排孔（约 100/cm²）加上独立进出微通道，废液不冲下游孔，才能在 210 mm² 这种“大面积”上保持低热阻和 <14 kPa 压降。
  3. 靶面微结构继续加分。凸凹坑、针翅、锯齿壁、斜断续肋：打断驻点之后的壁面射流边界层，并缓解射流入口堵塞。北大锯齿壁把 50 μm 槽压降从 76.9 kPa 降到 66.4 kPa，换热不丢。
  4. 倾斜射流可以换泵功。交大：θ=150° 时热阻最低；针翅打断射流螺旋，强化横流区。同泵功热阻 −26%，说明耦合的优化空间在角度和靶面，不在“再加密孔”。
  5. 歧管决定你能不能装进 1U。没有 MMC，长槽和交叉流会把射流优势吃掉。NTU 2024 把 MMC 和射流硬拼在一起，压降因突然收缩过大，综合并不优于基线——耦合失败通常是水力没设计，不是传热公式错了。

5.7.5 优势、短板、工艺：专门针对耦合件

优势
  • 同时打“对流热阻 1/(hA)”和“均温/交叉流”，这是单方案做不到的。
  • 文献热流覆盖 300–400 W/cm²（冷板级）到 3000 W/cm²（硅基近结区），覆盖当前 AI 热点报道区间。
  • 分流设计可以把压降压到十几个 kPa（Hou），落在 GPU 冷板常见 ≤20 kPa 窗内。
  • 与现有铜铲齿产线兼容路径清晰：盖板改成喷嘴板，槽底加针翅或锯齿，就是构型 A/C。
  • 再往上可以取消 TIM2（构型 D），热阻从 0.03 级迈向 0.02 级。
短板与工艺门槛
  • 层数和密封面翻倍。三层到五层铜，对位、钎缝、氦检都比单层铲齿难；EPTC 件用多步焊接+直接键合+CT 检腔。

  • 水力设计失败会得不偿失。突然收缩、进出不分、槽太深，压降上去、换热不涨（NTU 反例）。
  • 对中。射流阵列必须对准 GPU/HBM 热图，装配公差要进热仿真。
  • 构型 E 与今天机柜冷板不是同一产品。硅 MEMS、与 CoWoS 共设计，冷板厂做不了，也替换不了本季度 H200/B200 出货。

5.7.6 对 AI 算力冷板的选型建议

  1. 12–18 个月可交货的耦合件，走构型 A/C：现有铲齿或真空钎微通道冷板，盖板改成喷嘴板，槽底分区加针翅或浅凹坑，H/D 取 2–6，进出尽量分层。目标：在 OEM 流量点把 Rθ 从 ~0.03 往 0.02 推，压降仍 ≤20–25 kPa。
  2. 预研 1.2–2.5 kW 尖锐热点，走构型 D：三到五层铜，歧管+射流+针翅，评估直接键合取消 TIM2。对标锚点：EPTC 2025 的 0.028 K/W @ 2500 W（注意其 5 L/min、76 kPa 已超出不少机柜窗，要先做水力裁剪）。
  3. 不要用构型 E 当冷板 SKU。把它当作近结区技术雷达和与封装厂的接口预研；热流 3000 W/cm² 是硅上的数，不是 SXM 冷板接触面的数。
  4. 验收必须加两项：孔流量一致性、红外热点与喷嘴对中。只交出厂 Rθ 和 ΔP，看不出耦合有没有真正工作。
  5. 复合优先级更新：铲齿/微通道 → MMC → MMC+射流（本节约） → 金刚石均热片 → 封装内/硅背面 JMC。纳米流体仍然不进 TCS。

单纯“射流 + 微通道”已被 Sung & Mudawar、Intel DLMJ、浪潮中心射流、华为热密度分区等公开。新申请必须带GPU/HBM 双物理分区、可维护防堵、或滞止点局部金刚石。下面三案与同仓库专利报告 v1.4 §3.6 对齐；本调查报告只写原理和工程含义，不是 FTO。

5.8.1 方案 A（首选）：GPU / HBM 双物理杂交冷板

原理说明。B300/Rubin 不是均匀热源。GPU 逻辑区热流高，允许较高对流剪切，适合密射流 + 短微通道；HBM 热流较低，但结温更敏感，焊球和堆叠怕冲蚀、压装偏载，禁止射流覆盖。中间隔离肋同时是流道隔墙和抗弯筋，切断高速射流对 HBM 的串流。这与华为“按热密度混用结构”不同：必要特征是 HBM 无喷嘴 + 近壁流速上限 + 隔离肋双重功能 + 压降 ≤20 kPa。

7. 核心技术发展趋势

7.1 热路径变短TIM 和盖板已大于许多先进对流热阻。Wiwynn、Purdue、IMC-Si 都在消灭界面。冷板企业要准备流体接口标准化，而不只是把槽挖得更密。
7.2 按 power map 分配GB200/GB300/Rubin 是多芯片非均匀热源。生成式流道、仿生叶脉、变间距射流把 H/D、S/D 从“整板一个数”变成“分区一张表”。
7.3 单相吃干再交两相单相 D2C 约 1 500 W 吃力、2 000 W 近上限。两相价值是低流量、低压降、暖水进液。大规模预计 2026–2027，法规与运维比换热更硬。
7.4 射流迁到 1U能落地的三件事：限制空间回流（交叉流是第一敌人）；增材异形孔/旋流孔换均温；靶面针翅或凸凹坑，用 PEC 管住压降。合成射流短期进不了服务器。
7.5 金刚石先做片合理产品是热点尺寸的 CVD 片 + 金属化 + 低温键合。全金刚石微通道会先出现在雷达、激光、星载，而不是百万卡集群。
7.6 工质先统一规范OCP / ASHRAE W·S / GB/T 48023 把 TCS 收成可审计工业流体。石墨烯纳米流体更可能先改 FWS 板换逼近温差，不进 GPU 冷板。
7.7 制造三分流真空钎焊保质；隧道炉保量；增材做异形喷嘴和 MMC；CVD+键合做金刚石片。三条产线不要混成一个车间指标。
7.8 可靠性升级断流后热容极小，损坏窗口是秒到分钟级。必须带过滤、缓蚀、漏液检测和两相 CHF 裕量。行业常写约 90 s 中断窗口（待核实），设计上应按更短处理。

8. 对研发与产品的建议

8.1 量产冷板（12–18 个月）

  • 紫铜铲齿或真空钎焊微通道，分区变翅距对齐 GPU/HBM 热图。
  • B300：Rθ 目标 <0.028–0.030 °C/W（TGP 1100 W）或 <0.022–0.025（若按 1400 W）；压降 ≤20 kPa。
  • 只做 DI 水 / PG25；25 μm 过滤；铜缓蚀；禁纳米流体。
  • 真空钎或隧道炉，100% 气密；流量–压降–红外三条出厂曲线。
  • 按 OEM 温度–流量表测，不用 10 K 反算点出报告。

8.2 预研下一代（B300 1.4 kW → Rubin 1.8–2.3 kW）

  • 优先做 MMC + 热点射流 复合冷板，把 H/D、S/D、回流做成可制造三层板。
  • 并行评估热点面积 CVD 金刚石均热片的键合与 TBR，不要一上来开金刚石槽。
  • 两相仅做原理样机（低 GWP），与水基产线隔离。
  • 用生成式/拓扑方法出 2–3 个流道家族，绑定具体 power map。

8.3 明确不做的事

  • 不把纳米流体当 GPU 二次侧卖点。
  • 不用空气射流或合成射流参数直接缩放液冷冷板。
  • 不宣称“金刚石微通道已可上架百万卡”，除非成本、尺寸、键合同时关闭。
  • 不把浸没或两相当成当前超大规模默认。

9. 结论

AI 算力芯片液冷冷板已经从“要不要上液冷”变成“冷板内部用什么结构、界面还能不能再短一截”。功率尺必须对准英伟达最新 SKU，而不是停在 H100。

  • 功率包络：B300 Lenovo TGP 1 100 W（高）/ NVL72 报道 1 400 W（中）→ Rubin 报道 1 800–2 300 W（中低）。整柜 GB300 NVL72：135 / 155 kW。硅面积平均热流约 110–175 W/cm²，难的是总功率把 Rθ 压到 0.02 附近，以及多热点。
  • 微通道和微翅片（铲齿）是量产底座：优势是供应链和可靠性，短板是长通道均温与压降（见论文 Fig. 6 / Fig. 14）。
  • 冲击射流是单相强化的主升级件：三区结构见 Hussain Fig. 1；H/D = 2–6 见 Fig. 7；交叉流和异形孔见 SSH 2024。
  • 金刚石先做片：导热位差见 Element Six Fig. 1（1000–2200 vs 铜 400）；堆叠见 Fig. 2（片 + 微射流/微通道）。
  • 纳米流体实验室增益明确，综述自己列出的稳定性/污垢/电导率未关闭（Fig. 11），不进 TCS 基线。
  • 生成式流道是按 GB200/多芯片 power map 分配流量的方法（arXiv 2604.10941 / 2608.22787），不是新传热机制。
  • 规格上，芯片热阻、冷板压降、OEM 机柜流量表、TCS 水质、FWS W 类必须分表管理。禁止用 10 K 反推正式流量。
