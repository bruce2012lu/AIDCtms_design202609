## 各零件结构特征

**PLATE**（水平面累计面积：z=0 → 4733.0，z=0.20 → 2392.0，z=2.00 → 2661.6，z=3.50 → 3259.4，z=5.50 → 1204.0）
- 底面 0–0.2 mm 浅腔共 10 处，是 **TIM / 器件让位面，与水路不通**：2 处 27×28 在 (19.0,23.5)、(49.0,23.5)（对应两颗计算 die）；8 处 11×10 在 x=5.0 与 x=79.0，y=13.5/25.5/37.5/49.5（对应两列 HBM）。这些坐标与设计报告 v1.0 的锁定封装坐标一致。
- 短槽层 z 2.0–3.5（深 1.5）：**72 条 27.00 × 0.40 mm 槽沿 X**，分两组各 36 条落在两颗 die 投影内；两侧另有 2 个 22 × 71 的开放侧腔（X 2–24 / 71–93）。
- 回流层 z 3.5–5.5：PLATE 截面 1204.0 mm² = 周边框（664.0）+ **2 道 0.90 × 50 隔离肋**（X 16.10–17.00 / 78.00–78.90，Y 12.5–62.5）+ **30 条 0.30 × 50 细肋**（两侧 HBM 区）。

**COVER1**
- **128 个 D0.50 mm 直圆柱通孔，z 5.50→7.50（孔长 2.0）**。孔轴 **X = 22.0 / 25.0 / … / 43.0（die-A）与 52.0 / 55.0 / … / 73.0（die-B）**，节距 3.0、两组间隔 9.0；**Y = 26.9 / 29.9 / … / 47.9**，节距 3.0 → **两片 8×8，每 die 64 孔**。孔总面积 25.13 mm²。die-A 孔阵 X 22–43 居中于 die 投影 X 19–46（中心均为 32.5）。
  - ⚠ **不要用圆柱面的 `f.center()` 取孔轴**：build123d 在这里返回的是该面 bbox 的最小值，X 方向比真实轴线小 0.25（半个半径）。正确做法是取 `f.bounding_box()` 的 X/Y 中点。照 `center()` 的值（21.75…）去剖切会正好从两排孔之间穿过，剖面上一个孔都看不见。
- 回液窗口 1 处：**61.00 × 10.50 = 640.50 mm²**，X 17–78、Y 2.00–12.50（靠出液端）。
- 角窗 2 处：各 **7.00 × 10.50 = 73.50 mm²**，X 17–24 与 71–78、Y 62.5–73（靠进液端），**专给 HBM 侧腔旁路供液**。
- 下裙：X 17–78、Y 12.5–73 的围框，降到 z=3.50，与 PLATE 立壁互锁，侧向隔开射流腔与回流腔。

**COVER2**
- 静压箱被 **Y 12.50–23.20 的实体铜肋一分为二**（防进出短路的唯一屏障）：
  - **大腔 = 进液静压箱**，61.00 × 51.80 = 3077.8 mm²，X 17–78、Y 23.20–75，正覆盖全部 128 孔。
  - **小腔 = 出液汇集腔**，61.00 × 12.50 = 680.5 mm²，X 17–78、Y 0–12.50，正覆盖回液窗口。
- 进出液口各 1 处，**20 × 3 mm = 60.0 mm² 矩形**，开在 COVER2 侧壁，X 37.50–57.50、z 7.50–10.50：**y=75 侧进液（通大腔），y=0 侧出液（通小腔）**。
- **没有水嘴 / 法兰 / UQD 接口特征**。

## 流体域（板内无流体实体，铜间空腔即流体域）

外形包络减三个铜体 = **26653.4 mm³（约 26.7 mL），14 个连通块**：主流道 1 块 **26175.0 mm³**（bbox 91 × 75 × 8.5，z 2.00–10.50），其余 13 块是底面浅腔（2 处 die + 8 处 HBM + 3 个零面积伪块）。主流道**只在 Y± 两个端面各开 60 mm²**，即进出液口。

主流道水平截面积随 z：2.0–3.4 → 2661.6；3.6–5.4 → **4594.1**（整板单一回流层，91 × 71）；5.6 → 1001.3；6.5–7.4 → 812.6（= 回液窗口 640.5 + 2×73.5 角窗 + 128 孔 25.1）；7.6–10.4 → 3758.3（静压箱两腔之和）。

**流路 8 环**：① y=75 侧口进入 → ② 大腔静压箱稳压分流 → ③ 128 孔喷射 → ④ 冲击 PLATE 余铜顶面形成驻点 → ⑤ 壁面射流就近进 72 条短槽带走 → ⑥ 另有角窗旁路下灌左右 HBM 侧腔低速平流（无喷嘴） → ⑦ 两路同时上抽进 z 3.5–5.5 整板回流层汇集 → ⑧ 经 640.5 mm² 回液窗口进小腔，由 y=0 侧口流出。

## 设计点口径

几何是 **128 孔 / D0.50 / S3.0**，对应设计报告 **v1.0（20260913）** 的口径。
但 v1.0 文首已声明被取代：**v2.0（20260914）改为每 die 9×12 = 108、两 die 216 孔**，UC-01b 另把孔径冻结到 **D0.40**。
STEP 时间戳 09-21 晚于 v2.0，故该几何的喷嘴设计点落后于当前文档。**用户明确要求按 128 孔说明**，报告已按此执行，并在待确认项中留痕。
另：v1.0 是 8.5 mm 两层架构，asm_0921 是 12.5 mm 三层架构（新增独立静压箱盖），属结构演进。

- 结论：**推荐材质三件统一紫铜 C11000/TU1**（混材会同时踩接合不兼容 + 电偶腐蚀 + 热膨胀失配三个坑）；

- 最大失效风险：**内部隔断贴合不良导致内部短路**——不外漏、整板流阻可能仍在窗口内，但结温压不住且难查，需设计分区流阻标定单独验证。

## 与整机托盘的对应关系（据 Lenovo GB300 NVL2 托盘公开标注俯视图分析）

**一块本冷板 = 一颗 B300 SXM7 GPU，整托盘需 4 块。** 判据是底面浅腔布局：2 处 27×28（双计算 die）+ 8 处 11×10（八颗 HBM）正好是**一颗** B300 封装足迹。

照片可确认的事实：
- 整托盘**单进单出**：后面板上只有一个进液 UQD（上）+ 一个出液 UQD（下），两者同在后面板同一侧。
- **液冷位共 6 个 = 4 颗 B300 + 2 颗 Grace**（Grace 冷板更大且覆盖旁边内存区，足迹与 GPU 完全不同，**不能沿用本方案**）。
- **2 块 GB300 NVL2 板上下镜像**，每块 = 1 Grace + 2 GPU；标号「1」靠进液端、「2」靠出液端。
- 冷板间靠**外部管路**串接：刚性铜管 U 弯 + 金色波纹柔性金属管（装配与热胀补偿）+ 带金属压接套的黑色增强软管。
- 托盘保留 Fan Bay → NVMe / OSFP / PCIe Riser / BF3 / CX8 / PDB / BMC / 1G 板**走风冷，不在液冷回路内**。

照片看不清管内串并联。托盘水路按六路并联设计，见下节。ICD 若为串联，末级进液和射流孔压降要重算。

## 环境与踩过的坑（复用价值高）

- 本目录有独立 venv：`cad/.venv`，含 build123d 0.11.1 + cadquery-ocp-novtk 7.9.3.1.1 + ezdxf 1.4.4 + matplotlib + pytest + pyyaml。**不要往系统 Python 装 OCP**——系统 Python 是 `C:\veighna_studio`（VeighNa 量化环境），会被污染。
- **OCC 共面布尔必崩**：切除体与被切面共面会直接段错误（0xC0000005）。切除体务必加过切量冲出被切面。
- **OCC 有约 8–10% 的间歇性段错误**（30 次实测 27 次成功，崩溃点不固定，含 import 阶段）。`BOPAlgo_Options` 并行模式本来就是 False，分批切除也没消除。**结论：这是环境级不确定性，调用方必须能重试**。
- build123d 的 `project_to_viewport` 出 HLR 线框，每个零件约 0.1 s，适合做工程插图；直接把零件塞进 `Compound(children=...)` 会给它指定父节点，之后单独导出该零件 STEP 会失败，**装配时一律经 `Pos(0,0,0) *` 生成副本**。
- ezdxf：`doc.layers.add()` 不接受 `description` 参数；**ACI 颜色 7 是随背景反色，光栅化到白底会变白线消失**，图框要用 250。中文图注 ezdxf 字体管理器认不到系统字体，预览需关掉该图层由 matplotlib 重绘。
- **本机 Ansys 2026 R1 装在 E 盘**（早先只扫 `C:\Program Files` 误判为"没装 CAD"）。SpaceClaim 在
  `E:\cae\programfiles\Ansys2026\ANSYS Inc261\v261\scdm\SpaceClaim.exe`，可用 `Start-Process` 带 STEP 路径直接打开（约 50 s 载入，占用近 1 GB）；Fluent / Workbench / Mechanical 同目录下。
  桌面快捷方式集合在 `C:\Users\Administrator\Desktop\ansys`。
- **Cursor 的 `assets/` 资产文件名极长，整条路径逼近 MAX_PATH**：`Get-ChildItem` 能列出但 `Copy-Item` / `os.path.getsize` / `open` 全部报"路径不存在"。解决办法是加扩展长度前缀 `\\?\` + 绝对路径。
- PowerShell 是本会话默认 shell，`cmd /c "... & ..."` 的 `&` 和 `(x86)` 的括号会被 PowerShell 抢先解析而报错；多行 Python 也会被打散，**必须写成脚本文件再跑**。控制台中文乱码需 `chcp 65001`。
