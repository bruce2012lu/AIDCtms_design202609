# 一维矩形槽列设计

这是冷板单列矩形微通道的一维筛选方法。依赖只有 numpy。不引用冷板建模包。HBM 2026-09-29 的截面放在 `presets/hbm_column_20260929.json`，下次改流量、功率或截面时改这份 JSON，不必改求解器。

## 设计顺序

1. 先冻结列宽、列长、芯片分段、流量、功率、流体和铜的导热系数。这些是输入。
2. 用独立输入闭合尺寸链：`2*岸 + 槽数*槽宽 + (槽数-1)*肋宽 = 列宽`。肋宽不低于 0.30 mm，槽宽不低于 0.40 mm，岸宽不低于 0.30 mm，槽深/槽宽不高于 5。岸宽是输入。扫参时可以先算出刚好闭合所需的岸宽，再拿下限去剔除；低于下限的候选不算闭合。
3. 做体平均水力：水力直径、雷诺数、Hausen 努塞尔数（下限 4）、换热系数、直肋效率、对流温差、流体温升、Shah–London 直槽压降。加热长度用于格雷兹数，列长用于压降。压降和流速上限都用满槽流速。
4. 选流向：顺流 `coflow`，横流 `cross`，或中心进水 `center`。中心进水是中间槽从列中点进入、两端流出，两侧仍按横流对冲。七槽横流是偶数序号自高 Y 流向低 Y、奇数序号自低 Y 流向高 Y，高 Y 四条、低 Y 三条。
5. 沿列长做分段铜—流体推进。铜温迭代带欠松弛。比较两档迭代次数，平均温度和场温差的变化要小于约 0.05 K，再采用迭代更多的那一档。
6. 读受热壁的最低、平均、最高和温差，以及每一颗的平均温度。
7. 若场温差不够，或对流温差仍然高，就在尺寸链和 0.80 m/s 满槽流速上限内扫槽宽和肋宽。
8. 把结果写成 JSON，留给下一轮。

## 方法边界

这一套是筛选，不是 CFD，也不是试验结果。一维铜耦合通常比芯片测温和 CFD 面温更低、更平。

中心进水不把流体温升减半。中间槽分成两支，每支流量是该槽的一半，热量也是该槽的一半，所以每支流体温升仍等于整列流体温升。

`K_split = 1.5` 是假定的三通局部阻力，不是实测值。流速上限 0.80 m/s 约束满槽流速，不约束更慢的支路。

## 命令

在本目录执行：

```text
python -m channel1d --preset presets/hbm_column_20260929.json --bulk-check
```

保留截面 `7 × 0.80 mm × 2.00 mm`、肋 `0.80 mm`、`0.20 L/min`、`99.22 W` 应得到流体温升约 7.179 K，对流温差约 14.81 K，直槽压降约 60.9 Pa。三者与目标之差都要在 0.05 以内，命令才返回通过。

分段求解和写出下一轮 JSON：

```text
python -m channel1d --preset presets/hbm_column_20260929.json --solve --ny 50 --iters 6400 --out result.json
```

`--sweep` 会在中心进水方案上扫槽宽和肋宽。默认网格较密，只在需要换截面时使用。
