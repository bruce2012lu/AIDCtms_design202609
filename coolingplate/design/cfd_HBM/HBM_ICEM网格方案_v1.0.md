# HBM 冷却区共轭网格 v1.0

单通道六面体 **965 888**，低于 100 万，因此同一套边界层又做了单侧 8 槽阵列（**6 429 192**）。网格是共形 HEX，流体、铜、TIM 共节点。本机 ICEM 能打开，但这套多块材料分区是按 ICEM 边分布直接写成 Fluent msh，没有在 ICEM GUI 里再切一次 blocking。

流固耦合按设计报告第 10 章的共轭传热：铜必须进计算域，壁面要解到 y⁺ < 1。不是结构双向流固耦合。

## 几何

数字来自 `design/calc/model.py`、`cad/params/cp_b300_jm01.yaml` 和报告 §8.1 / §9.6 / JM01-A3。

| 项 | 值 |
|---|---|
| 槽 | 0.60 × 1.50 mm，沿 Y，列长 50 mm |
| 节距 / 肋 | 1.30 mm / 0.70 mm |
| 单侧条数 | 8。两侧合计 16，与 0.40 L/min 的槽速 0.463 m/s 一致 |
| 岸 | 每侧 (11 − 9.70) / 2 = 0.65 mm |
| 厚度 | 余铜 2.0 + 槽 1.5 + 间隙 H 2.0 + 盖板 2.5。TIM 80 μm |
| 四颗堆叠 | 列坐标 0–11、13–24、26–37、39–50 mm。中间 2 mm 不加热 |

JM01-A3 的盖板在 HBM 区没有喷嘴，但 H = 2.0 mm 的水缝还在，槽顶是敞开的。一维模型把槽当成封闭矩形（Dh = 0.857 mm）。网格按敞开的剖面建，流量在槽和间隙之间怎么分，交给求解器。

局部坐标：x 沿槽宽，y 沿流动，z 向上，z = 0 在槽底。y = 0 是列的下游端（靠出液歧管），y = 50 是上游端（靠进液歧管）。两端各加 10 × 0.857 = 8.571 mm 延长段。

单通道取一个节距 1.30 mm，两侧切在肋中面。阵列取左列整宽 11 mm。右列与左列镜像，不另做一套网格。

## 边界层

槽道设计点是层流，Re ≈ 603（DP-A）/ 724（DP-B）。报告里 ≤ 3 μm 的首层是 GPU 射流驻点，不是这条槽。按封闭槽、全部 HBM 流量都挤在 16 条槽里估算壁面剪切（偏保守）：

| 点 | 近壁速度 | 首层 8 μm 的 y⁺ |
|---|---|---|
| DP-A | 0.463 m/s | 0.66 |
| DP-B | 0.556 m/s | 0.72 |

流体壁（槽两侧、槽底、肋顶、盖板底面）首层 **8 μm**，相邻比 **≤ 1.2**，每侧不少于 10 层。槽高方向 34 层，间隙高度方向 40 层，两端都是 8 μm。固体界面第一层 **16 μm**（不超过流体首层的 2 倍），余铜 18 层，盖板 15 层，TIM 6 层（每层 13.3 μm）。铜/流体交界面上 16 μm 对 8 μm，所以整条 z 向的最大相邻比是 2.0；流体内部仍然 ≤ 1.2。

笛卡尔 HEX，正交质量为 1。最扁的格子大约是流向 0.66 mm 对壁面法向 8 μm，长宽比约 80。

## 体区与边界

| 区 | 单通道单元 | 阵列单元 |
|---|---:|---:|
| fluid | 459 136 | 3 205 248 |
| solid_cu | 472 192 | 2 993 904 |
| solid_tim2 | 34 560 | 230 040 |
| 合计 | **965 888** | **6 429 192** |

TIM 只铺在四颗 11 mm 堆叠下面。堆叠之间和延长段的铜底是绝热壁。

| 边界 | 设定 |
|---|---|
| inlet | 质量入口，在 y = 58.571 mm。单通道 4.134×10⁻⁴ kg/s（0.40 L/min 的 1/16）；阵列 3.307×10⁻³ kg/s（单侧 0.20 L/min）。40 °C |
| outlet | 压力出口 0 Pa（表压），在 y = −8.571 mm |
| wall_heat | TIM 底，20.5 W/cm² = 205 000 W/m² |
| wall_cu_fluid / wall_tim_cu | 耦合壁 |
| sym | 仅单通道，肋中面 |
| wall_side | 仅阵列，x = 0 和 x = 11 mm |
| wall_adiabat | 盖板顶、延长段端面、堆叠之间的底面 |

材料沿用报告和 UC-01b：铜 390 W/m·K；TIM k = 8.818 W/m·K（80 μm，对应两 die 的 R = 0.006 °C/W 那一档，不是 HBM 单独拟合的接触热阻）。水用 40 °C：ρ = 992.2 kg/m³，μ = 6.53×10⁻⁴ Pa·s。

侧面切在 HBM 外形 11 mm 上。真实水缝会再延伸到隔离肋（向外 0.5 mm）。要做间隙流量分配时，把这块岸加进去，槽内边界层不用重排。
