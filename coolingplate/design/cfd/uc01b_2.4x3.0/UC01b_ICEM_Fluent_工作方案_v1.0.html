0.　结论（先读这一页）

本算例只做一孔 + 三短槽 + ±X 回液缝上抽的流体单元胞。 禁止 95×75 mm 整板、禁止 128 孔共轭、禁止把槽当成「一条长河」的 bank 流。 2.0 L/min 是整板总流量，不是单孔。20 kPa 是冷板本体窗，不含 UQD。 本文是开工令，不是仿真报告；结果报告必须等 Fluent 至少写出残差。

1.　目标、范围、非目标

1.1　目标

  1. ICEM 建出与 calc/model.py GEO 及 UC01_壁面射流与三槽流路说明.html / fig_walljet.py 对齐的单孔流体域。
  2. 打出 Fluent 可读网格：优先结构化 hex（孔 O-grid + 槽 H 网格）；不行则 tet/prism 并声明。
  3. TUI journal 启动 Fluent：层流、水 40 °C、ṁ = 1.224938e-4 kg/s、回液缝压力出口。已收敛场是 iter 8587。
  4. 至少得到残差与若干监视器（ΔP，若可能则 wall_imp 面平均 h）。不要求过夜收敛。
  5. 用实测残差/监视器写结果报告。禁止编造云图。

1.2　非目标（本周禁止）

  • 整板、128 孔、HBM、静压箱+水嘴全模；
  • 用本单元胞 h 外推整板 Rθ,c-in（设计报告 v2.0 §10.3）；
  • 1/4 对称；长槽 bank 流；
  • PG25 / 热点 2.5× / 堵塞 20%；
  • 把 2.0 L/min 当单孔流量；把 20 kPa 当「含 UQD 的接口压降」。

4.　ICEM 工作流

顺序锁死：几何 → 命名 parts → blocking → 网格 → 质量表 → Fluent msh。不得先加密再补面名。

4.1　几何

ICEM 内点/线/面/体素构造，布尔成单一流体体，与 §2 误差 < 0.01 mm。孔必须是圆；应急网格允许等面积方孔（边长 0.3545 mm），主 replay 仍建圆孔。

set AWP_ROOT261=E:\cae\programfiles\Ansys2026\ANSYS Inc261\v261 "%AWP_ROOT261%\icemcfd\win64_amd\bin\icemcfd.bat" -batch -script build_uc01b.rpl GUI：File → Replay Scripts → 打开本目录 .rpl。

4.2–4.3　Parts 与 blocking

Parts 见 §2.6。孔+箱 O-grid；间隙 H 网格；三槽各一砖；回液竖砖与槽端对接；Y 两侧点数一致。 O-grid 失败则 tet+prism（首层仍 ≤3 μm），日志写明「非 hex」。
