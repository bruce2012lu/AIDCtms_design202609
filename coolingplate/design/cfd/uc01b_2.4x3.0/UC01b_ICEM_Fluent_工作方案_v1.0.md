### 2.2 Y 向三槽装填（必须 2.4 mm 刚好）

`3×槽 + 2×满肋 + 2×半肋 = 3×0.40 + 2×0.40 + 2×0.20 = 2.40 mm`。

| Y 区间 (mm) | 零件 | 说明 |
|---|---|---|

| [−1.00, −0.60] | 侧槽 − | 中心 Y = −0.80 |
| [−0.60, −0.20] | 满肋 | |
| [−0.20, +0.20] | **中槽** | 正对孔 |
| [+0.20, +0.60] | 满肋 | |
| [+0.60, +1.00] | 侧槽 + | 中心 Y = +0.80 |
| [+1.00, +1.20] | 半肋（周期/对称面） | 邻胞共享 |

侧槽中心距孔轴 r = 0.80 mm ≈ **2.0 D**，落在壁面射流扫过带（说明页图 2）。

### 2.3 X 向回液与槽长

| X 区间 (mm) | 零件 |
|---|---|
| [−1.50, −1.10] | −X 半缝（上抽） |
| [−1.10, +1.10] | 三槽 + 间隙主体（槽长 2.20 mm） |
| [+1.10, +1.50] | +X 半缝（上抽） |

若有人要求「缝宽 0.80 全部落在本胞、不与 X 邻胞共享」，记为备选 **UC-01b-isolated**，本方案不采用。

### 2.4 Z 向堆叠（流体-only coupon）

| Z (mm) | 域 | 网格要点 |
|---|---|---|
| 0 → 1.50 | 三槽腔 + 两端回液缝根部 | 槽底 = wall_imp（中槽驻点在此） |
| 1.50 → 3.50 | 间隙 H=2.0；肋顶是壁面射流贴壁面 | 肋顶加密 |
| 3.50 → 6.00 | 盖板孔段 ⌀0.40，长 2.5 mm | 轴向 ≥ 8 层；径向 ≥ 8–12 |
| 6.00 → 8.00 | 短静压箱 ≥ 2 mm | 顶面 = inlet_jet |

固体铜、盖板实体、余铜 **第一案不建**。

### 2.5 流路（禁止改口）

**下射 → 驻点 → 壁面射流沿 ±X（并扫入侧槽）→ 回液缝向上抽走。**

- ① 自由射流：孔内 / 间隙中尚未撞壁，方向 −Z。
- ② 驻点：仅中槽底正对孔。
- ③ 壁面射流：转 90° 后贴肋顶 / 槽口的薄剪切层，**不是**槽底导管流。
- 回液：±X 端缝向上。Y 向邻孔在 Y=±1.2 mm 相遇，预期 **喷泉 / 上洗**。

### 2.6 命名零件（ICEM parts = Fluent zones）

| Part | 类型 | 位置 |
|---|---|---|
| `inlet_jet` | mass-flow-inlet | 静压箱顶（或孔顶，若未建箱） |
| `wall_orifice` | wall | 孔圆柱壁 |
| `wall_lid` | wall | 盖板下表面（间隙顶，除孔外） |
| `wall_imp` | wall，等温建议 50 °C | 槽底 + 驻点铜壁 |
| `fin` | wall | 肋侧壁 + 肋顶 |
| `return_slot` | pressure-outlet | 两条回液缝顶面（上抽出口） |
| `periodic_y` 或 `SYM` | periodic 或 symmetry | Y = ±1.2 mm |
| `fluid` | cell zone | 全部流体 |

X 向两端是回液出口，**不是**周期面。

### 2.7 D = 0.40 而不是 0.50

主方案锁定 **D = 0.40 mm**。仅当 ICEM 孔周 O-grid 在 0.40 上数值病态（边长比极端、负体积）时，允许先用 0.50 调试 blocking，但必须：

1. 在日志里写明原因；
2. **仍然交付 0.40 的 replay / 网格作为主文件**；
3. 不得把 0.50 网格的 Nu 当成 0.40 结果。

本方案判断：0.40 与槽宽同量级，blocking 并不比 0.50 更难，**不换直径**。

|---|---|---|---|
| 乐观 Martin 面平均 | 51470 W/m²K | 0.0128 °C/W | Re 外推 |

### 3.4 必须写在方案里的两句约束

1. **20 kPa 是冷板本体压降窗（目标 18、上限 20），不含 UQD / 快接头。** 单元胞孔口只有约 1–3 kPa，对不上 20 kPa 是正常的。
2. **2.0 L/min 是整板总流量。** 单孔 0.0125 L/min。把 2.0 填进 mass-flow-inlet 视为本计划失败。

## 4. ICEM 工作流

顺序锁死：**几何 → 命名 parts → blocking → 生成网格 → 质量表 → 写出 Fluent msh**。不得先加密再补面名。

### 4.1 几何

优先在 ICEM 内用点/线/面/体素构造（便于 replay），不必先经过整板 STEP。

1. 建外盒与半缝、三槽腔、间隙、孔圆柱、短静压箱。
2. 布尔得到单一流体体。
3. 尺寸与 §2 误差 < 0.01 mm。
4. 孔必须是圆；第一案可用等面积方孔（边长 0.3545 mm）作 **应急网格**，但 ICEM 主文件仍应建圆孔。

批处理：

```bat
set AWP_ROOT261=E:\cae\programfiles\Ansys2026\ANSYS Inc261\v261
set AWP_ROOT=%AWP_ROOT261%
"%AWP_ROOT261%\icemcfd\win64_amd\bin\icemcfd.bat" -batch -script build_uc01b.rpl
```

GUI：ICEM → File → Replay Scripts → Replay / 打开本目录 `.rpl`。

### 4.2 Parts

按 §2.6 建 family。导出前用 `ic_geo_set_part` / blocking association 对齐，避免 Fluent 里出现 `wall.1` 匿名面。

### 4.3 Blocking（hex 优先）

| 区域 | 拓扑意图 |
|---|---|
| 孔 + 静压箱 | O-grid，径向 ≥ 8–12，轴向 ≥ 8 |
| 间隙 | H 网格，法向 ≥ 20；肋顶第一层 ≤ 3 μm |
| 三槽 | 各一条砖，槽宽 ≥ 8 层，槽深几何增长 |
| 回液缝 | 竖向砖，与槽端 1:1 对接 |
| Y 边界 | 半肋处周期或对称，两侧点数必须一致 |

若 O-grid 关联失败：改 tet + 壁面 prism（首层仍 ≤ 3 μm），在日志写明「非 hex」，**不要假称已做结构化质量检查**。

### 4.4 网格指标

| 指标 | 目标 | 第一案可接受 |
|---|---|---|
| 壁面第一层 | ≤ 3 μm | 必须 |
| 驻点法向层数 | ≥ 15 | ≥ 10 可开算，报告注明 |
| 孔径向 | ≥ 8–12 | 8 |
| 孔轴向 | ≥ 8 | 8 |
| 间隙法向 | ≥ 20 | 12 |
| 单元数（hex） | 0.8–2.5 M | 为出残差可先 0.2–0.8 M，正式套再加密 |
| 正交质量 | min > 0.15 | 负体积 = 失败 |
| y⁺（设计点） | < 1 | 用 V=1.66 m/s 估：3 μm 大约 y⁺≈0.5–1.2 |
| y⁺（V4 Re=3000） | < 1 | 速度×3，可能要 1 μm；本周可不跑 V4 |

粗/中/细 1 : 1.5 : 2.25 是 G2 关闭条件，不是第一次出残差的条件。

### 4.5 质量门（未跑 ICEM 不得声称已检查）

必须留下：单元数、min/max 正交、负体积数、第一层厚度、导出 `.msh` 路径。许可证或 GUI 挡住时，保留脚本 + 完整错误日志。
