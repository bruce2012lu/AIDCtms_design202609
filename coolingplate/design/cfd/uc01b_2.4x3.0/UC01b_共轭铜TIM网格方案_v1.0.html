2.　为什么必须共轭（不能再用 Cu 壳）

model.py 湿润面积增益：单 die 35 槽，A_fin=35×2×1.50×27 mm²，A_bot=35×0.40×27，A_wet/A_die = AREA_GAIN ≈ 4.25。热从 TIM 底进入后要在 2 mm 铜里横向扩展，再经肋导入三槽。Option A 把 q'' 打在流体底再加 2 mm 壳，铜内没有真实肋导热路径，也没有 TIM 厚向网格。

R_wall = t_base / (k_Cu · A_2DIE) = 0.002 / (390 × 1.512e-3) = 0.003392 °C/W R_c-in = R_TIM2 + R_wall + R_conv　　R_j-in = R_pkg + R_c-in R_TIM2 默认 0.006（链区间 0.004–0.008）　　R_pkg = 0.008–0.012

CHT 把 TIM 与铜建成实体：界面 wall_tim_cu、wall_cu_fluid 耦合。才能看到 spreading 和 AREA_GAIN，而不是壳上的一维 ΔT=q''·t/k。
