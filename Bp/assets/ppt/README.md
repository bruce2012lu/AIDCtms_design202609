
`_preview/` 是验证产物，可随时删除，不影响交付。

## 3. 替换单张图片的方法

三种方式，任选其一：

1. **改脚本重渲染（推荐）**：编辑 `make_charts.py` 中对应的 `cNN()` 函数，跑 `python -c "import make_charts as m; m.cNN()"`，再跑 `make_ppt.py`。数据、图注、来源标注都在同一个函数里，改完自洽。
2. **直接换 PNG**：用同名文件覆盖本目录下的 PNG，再跑 `make_ppt.py`。`make_ppt.py` 按比例自适应缩放，宽高比不必完全一致；但**分辨率需 ≥ 幻灯片显示尺寸的 200 dpi**，否则 `verify_ppt.py` 会报 FAIL。
3. **在 PowerPoint 里替换**：右键图片 → 更改图片。此法不会回写到本目录，下次跑 `make_ppt.py` 会被覆盖，仅适合一次性微调。
