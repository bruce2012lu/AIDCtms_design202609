## 1. 缺口二：倒推所需价格

### 1.1 固定费用口径（两档）

来源：BP v2.1 §10 资金用途表（阶段 1 上限 800 万元）。**【实证】**（内部预算文件）

| 科目 | 阶段 1（万元） | 是否费用性 | 纳入 F1 | 纳入 F2 |
|---|---:|---|---|---|
| 核心团队与专项工程 | 220 | 是 | ✔ 220 | ✔ 220 |
| 产品 NRE／软件／IP | 115 | 是（一次性） | ✔ 115 | ✘ |
| 样机／物料／工装 | 130 | 是（一次性） | ✔ 130 | ✘ |
| 测试／认证／客户验证 | 95 | 是 | ✔ 95 | ✔ 50（经常性部分） |
| 供应商 NPI／授权制造 | 50 | 是 | ✔ 50 | ✔ 20（经常性部分） |
| PoC／订单营运资金 | 110 | **否（可回收）** | ✘ | ✘ |
| 保险／法务／网络安全／服务 | 30 | 是 | ✔ 30 | ✔ 30 |
| 董事会预备金 | 50 | 是（备用） | ✔ 50 | ✘ |
| **合计** | **800** | | **F1 = 690** | **F2 = 320** |

- `F1 = 800 − 110 = 690 万元/年`：阶段一需由毛利或注资覆盖的**全部费用性支出**（含一次性 NRE 与样机）
- `F2 = 220 + 50 + 20 + 30 = 320 万元/年`：**稳态经常性固定费用**（团队 + 持续测试认证 + 供应商质量 + 保险法务）

F2 是判断"业务能否自我维持"的正确分母；F1 是判断"阶段一能否靠自身回收"的分母。**两者都必须报告，只报 F2 会低估投入，只报 F1 会低估稳态可行性。**

### 1.4 第一个核心矛盾

```
最乐观 BOM 情景下的同边界总成本  = 840 元/kW
国内运营商包价上限（两样本收敛） = 685–715 元/kW
```

**即：即使 BOM 落在假设区间的最低端，同边界总成本仍高于国内运营商包价上限约 17%–23%。** 在中值 BOM（650）下，总成本为包价上限的 **1.52–1.59 倍**。

复算：`840 ÷ 715 = 1.175`；`840 ÷ 684.75 = 1.227`；`1,090 ÷ 715 = 1.524`；`1,090 ÷ 684.75 = 1.592` ✔

**要在 715 元/kW 的价格下取得非负项目贡献，BOM 必须 ≤ 275 元/kW**（`715 − 440 = 275`），即比假设中值低 **58%**（`1 − 275/650 = 57.7%`）。

### 1.5 三种可能的解释（必须全部呈现，不得只留有利的一种）

| # | 解释 | 可检验性 | 检验方法 |
|---|---|---|---|
| **H1** | 成本假设偏高：真实 BOM 可能在 275–450 元/kW | **可在 4–6 周内以近零成本检验** | 四 SKU 关键件书面询价（工具包一） |
| **H2** | 招标样本不可外推：包价上限可能由在位者的平台摊销、垂直整合、既有服务网络与低边际固定成本支撑，或为进入运营商框架的战略性低价 | 可部分检验 | 客户/渠道访谈取得分项成交价；观察在位者盈利（曙光冷板 10.36% 且 2026H1 亏损扩大，支持"低价+微利"假说） |
| **H3** | 国内运营商裸设备渠道对新进入者结构性不成立 | 由 H1、H2 的检验结果反推 | 若 H1 检验后 BOM > 450 元/kW，则 H3 成立，业务重心必须转向海外／服务／非运营商渠道 |

**H2 的支持证据（一手）：** 曙光数创冷板液冷毛利率 10.36%，2026 H1 冷板收入 +290% 而归母净利 −7,340 万元、经营现金流 −2.42 亿元。这与"在位者在该价格带上仅取得极薄毛利甚至亏损"一致。**这条证据同时意味着：即使新进入者能把成本压到在位者水平，该渠道的回报也不足以支撑独立业务的固定费用。**

### 1.7 倒推所需毛利率与盈亏平衡容量

公式：

```
CM_intensity = P_netrev − C_total                （元/kW）
CM_rate      = CM_intensity ÷ P_netrev
BE_capacity  = F ÷ CM_intensity                  （kW/年）
```

以中值成本 `C_total = 1,090 元/kW` 计：

| 价格 P（元/kW） | CM 强度（元/kW） | CM 率 | BE @F2=320 万（MW/年） | BE @F1=690 万（MW/年） |
|---:|---:|---:|---:|---:|
| 685（佛山实证上限） | **−405** | 负 | 无盈亏平衡点 | 无盈亏平衡点 |
| 715（南京实证上限） | **−375** | 负 | 无盈亏平衡点 | 无盈亏平衡点 |
| 840 | −250 | 负 | 无 | 无 |
| 1,090 | 0 | 0% | ∞ | ∞ |
| 1,200 | 110 | 9.2% | **29.09** | 62.73 |
| 1,440（海外参照低位） | 350 | 24.3% | **9.14** | 19.71 |
| 1,500 | 410 | 27.3% | **7.80** | 16.83 |
| 1,730（海外参照高位） | 640 | 37.0% | **5.00** | 10.78 |
| 1,800 | 710 | 39.4% | 4.51 | 9.72 |

复算样例：`1,500 − 1,090 = 410`；`410 ÷ 1,500 = 27.33%`；`3,200,000 ÷ 410 = 7,805 kW = 7.80 MW`；`6,900,000 ÷ 410 = 16,829 kW = 16.83 MW` ✔

### 1.8 第二个核心矛盾：倒推所需毛利率 vs 实证锚点

| 情景 | 所需 CM 率 | 实证对照 | 判定 |
|---|---:|---|---|
| P = 1,200 元/kW，容量 29 MW/年 | 9.2% | 曙光冷板 10.36% | 毛利率可达，但 **29 MW/年 的容量不可达**（见 §3.4） |
| P = 1,500 元/kW，容量 7.8 MW/年 | **27.3%** | 曙光冷板 10.36%；申菱设备 21.46%；Modine 数据中心 20.2% | **所需毛利率高于所有国内一手披露的相关口径**，仅英维克境外 52.64% 可支持 |
| P = 1,730 元/kW，容量 5.0 MW/年 | **37.0%** | 无国内一手支持 | 仅海外市场可能 |

**结论（必须如实呈现）：能让阶段一固定费用在可达容量下平衡的价格，其对应的所需毛利率是 27%–37%，而国内可比公司一手披露的相关毛利率是 10.36%–23.60%。倒推所需毛利率显著高于国内行业实证水平，缺口约 4–27 个百分点。唯一有一手实证支持该毛利率水平的是海外市场（英维克境外 52.64%）与服务/解决方案收入（申菱 31.63%、曙光服务 51.02%）。**

### 1.9 敏感性（龙卷风数据表）

基准：`P = 1,500 元/kW`，`BOM = 650`，`C_total = 1,090`，`CM = 410 元/kW`，`F2 = 320 万元`

| 变量 | 变动 | CM 强度（元/kW） | 相对基准 | BE @F2（MW/年） |
|---|---|---:|---:|---:|
| **ASP** | −20%（1,200） | **110** | −73.2% | 29.09 |
| **ASP** | +20%（1,800） | **710** | +73.2% | 4.51 |
| **BOM** | +15%（747.5） | 312.5 | −23.8% | 10.24 |
| **BOM** | −15%（552.5） | 507.5 | +23.8% | 6.31 |
| **销量** | ±50% | 410（不变） | 0% | 7.80（不变） |

复算：`1,200−1,090=110`，`110/410−1 = −73.17%`；`1,800−1,090=710`，`710/410−1 = +73.17%`；`650×1.15=747.5`，`1,500−(747.5+440)=312.5`，`312.5/410−1 = −23.78%`；`650×0.85=552.5`，`1,500−992.5=507.5`，`507.5/410−1 = +23.78%` ✔

**排序（对项目贡献的影响力）：ASP（±73%）> BOM（±24%）> 销量（0%，但影响缺口绝对额）。**

销量的正确解读：销量不改变单位贡献强度和盈亏平衡点，只改变"距离盈亏平衡有多远"。在 P=1,500、V=4 MW/年（约 20 台 200 kW）时：年贡献 `4,000 × 410 = 164 万元`，对 F2=320 万元的缺口为 **−156 万元**；V±50% 使缺口在 **−238 万元 至 −74 万元** 之间。**在任何 ±50% 的销量情景下，阶段一均不能达到 F2 盈亏平衡。**

复算：`4,000 kW × 410 元/kW = 1,640,000 元 = 164 万元`；`164 − 320 = −156`；`2,000×410=82 万元 → 82−320 = −238`；`6,000×410=246 万元 → 246−320 = −74` ✔

### 1.10 价格可行域（200 kW 档，同边界）

| 区间（元/kW） | 判定 |
|---|---|
| **< 840** | 在最乐观 BOM（400）下仍为负贡献 → **必然亏损** |

## 2. 缺口三：责任敞口量化

### 2.1 单台 200 kW CDU 服务的 IT 资产价值

| 输入 | 值 | 依据 |
|---|---|---|
| 机柜 IT 功率（GB300 NVL72 TDP） | 135 kW | **【实证】** Lenovo GB300 Product Guide, Table 27（一级原厂规格） |
| 液冷占比 | 约 90% → 液体负荷 121.5 kW/柜 | **【实证／推导】** 同上；`135 × 0.90 = 121.5` |
| 服务器价值强度 | 21.2 美元/W | **【可比】** Epoch AI 一 GW AI 数据中心 TCO 模型（二级，第三方模型） |
| 汇率 | 7.2 元/美元 | **【假设】** |

**推导：**
```
单柜服务器价值 = 21.2 × 135,000 = 2,862,000 美元 = 2,060.6 万元
200 kW CDU 覆盖柜数 = 200 ÷ 121.5 = 1.646 柜
单台 200 kW CDU 服务的 IT 资产价值 = 1.646 × 2,060.6 = 3,392 万元
```
复算：`21.2×135000 = 2,862,000`；`×7.2 = 20,606,400 元 = 2,060.64 万元`；`200/121.5 = 1.6461`；`1.6461 × 2,060.64 = 3,392.0 万元` ✔

**交叉验证：** 独立三级来源称"GPU 整柜数百万美元级"，与本模型 286 万美元/柜一致。两条路径独立且量级吻合。

**低密度改造情景（对照）：** 40 kW/柜液体负荷、5 柜、通用服务器约 5 美元/W → 单柜 `40,000×5×7.2 = 144 万元`，5 柜合计 **720 万元**。敞口相差 4.7 倍，**说明客户分层直接决定责任敞口量级**。

### 2.2 敞口与合同额、毛利的比例

以国内实证包价上限计：`合同额 = 715 × 200 ÷ 10,000 = 14.30 万元`；`毛利 = 14.30 × 10.36% = 1.4815 万元`

| 事故情景 | 潜在损失 | ÷ 合同额 | ÷ 项目毛利 |
|---|---:|---:|---:|
| 单块 GPU 基板损坏（3.5–5.0 万美元，三级） | 25.2–36.0 万元 | **1.8–2.5 倍** | **17–24 倍** |
| 单柜 IT 资产全损 | 2,060.6 万元 | **144 倍** | **1,391 倍** |
| 200 kW CDU 覆盖范围全损（1.65 柜） | 3,392 万元 | **237 倍** | **2,290 倍** |
| POD 级级联（32–72 柜，三级） | 6.6 亿–14.8 亿元 | 4,600–10,400 倍 | 44,500–100,300 倍 |
| 行业惯例责任上限（合同价 10%–20%，三级指引） | 1.43–2.86 万元 | 0.1–0.2 倍 | 1.0–1.9 倍 |

复算：`715×200/10000 = 14.30`；`14.30×0.1036 = 1.48148`；`35,000×7.2/10,000 = 25.2`；`50,000×7.2/10,000 = 36.0`；`25.2/1.48148 = 17.01`；`36.0/1.48148 = 24.30`；`2,060.64/14.30 = 144.10`；`2,060.64/1.48148 = 1,390.9`；`3,392/14.30 = 237.2`；`3,392/1.48148 = 2,289.6`；`2,060.64×32 = 65,940 万元 = 6.59 亿`；`2,060.64×72 = 148,366 万元 = 14.84 亿` ✔

### 2.3 关键洞察（可直接用于董事会）

1. **一次 50 ml 的冷却液滴落造成的单块基板更换成本，就等于整个合同额的 1.8–2.5 倍、整个项目毛利的 17–24 倍。** 即：**在最小可想象的事故中，供应商已经赔掉了 17–24 个同规模项目的全部毛利。**
2. **行业惯例的"合同价 10%–20% 责任上限"在此业务中对客户毫无意义**——1.43–2.86 万元的上限连一块基板都赔不起。因此客户的理性诉求必然是**不封顶或设超级上限**，而这是新进入者绝对不能接受的。**这意味着责任谈判不是"争取更好条件"，而是"业务是否存在"的判定。**
3. **责任封顶不是谈判技巧，是业务成立的前提条件。** 若无法取得书面责任上限 + 间接损失排除 + 可投保确认，则单个项目的尾部损失可以在一次事故中消灭整个阶段一预算（800 万元）的 2.6 倍（单柜全损 2,060.6 万元 ÷ 800 万元 = 2.58 倍）。
4. **技术故障隔离是唯一能降低敞口本身（而非转移敞口）的手段。** 合同上限、保险、供应商追偿都只是转移；把"每个 CDU 覆盖的 IT 资产价值"从 3,392 万元降到 720 万元（低密度改造客户）是 4.7 倍的敞口削减，比任何条款谈判都有效。**这直接决定阶段一的客户选择：优先低密度存量改造，而非高密 GB300 集群。**

复算：`2,060.64/800 = 2.576` ✔；`3,392/720 = 4.71` ✔

### 3.2 单项目峰值现金占用（按每 MW CDU 容量）

现金支出（元/kW → 万元/MW）：`BOM 650 → 65`；`安装/SAT 150 → 15`；`物流 50 → 5`

| 价格情景 | 合同额（万元/MW） | 履约保证金 5%（万元） | **峰值现金占用（万元/MW）** |
|---|---:|---:|---:|
| P = 715（实证上限） | 71.5 | 3.58 | **88.6** |
| P = 1,200 | 120.0 | 6.00 | **91.0** |
| P = 1,500 | 150.0 | 7.50 | **92.5** |

公式：`峰值 = BOM现金 + 安装现金 + 物流现金 + 履约保证金 = 65 + 15 + 5 + 0.05 × 合同额`
复算：`65+15+5+0.05×120 = 91.0` ✔

**本模型采用 91 万元/MW 作为峰值现金占用基准。** 该峰值出现在"安装完成至终验回款到账"之间，即最早第 12 周、最晚可延至第 36 周以后。

**假设：无客户预付款。** 依据：佛山/南京/浙江三个运营商公开文件均未见预付款条款；C-DAC 的 30% 预付款需要同额银行保函（占用授信，本身有成本）。**若能取得 30% 预付款，峰值可下降约 `0.30 × 合同额`（P=1,200 时为 36 万元/MW，降幅 40%）——这使"争取预付款"成为现金层面最高杠杆的单一谈判目标。**
复算：`0.30 × 120 = 36`；`36/91 = 39.6%` ✔

### 3.3 800 万元预算下的并行项目数（硬约束）

BP v2.1 §10 明确"PoC／订单营运资金 110 万元，仅用于已签项目"。

| 可用营运资金口径 | 金额（万元） | ÷ 91 万元/MW | 并行容量 |
|---|---:|---:|---|
| 严格口径（仅 PoC/订单营运资金 110） | 110 | **1.21 MW** | **约 1 个 1 MW 项目，或 6 台 200 kW** |
| 含董事会预备金（110 + 50） | 160 | **1.76 MW** | 约 1 个 1.7 MW 项目；**不足以支撑 2 个并行 1 MW 项目并保留缓冲** |
| 全部预算（800，实际不可用，690 已承诺） | 800 | 8.79 MW | 仅作上限参照 |

复算：`110/91 = 1.209`；`160/91 = 1.758`；`800/91 = 8.791` ✔

**年吞吐量：** 单项目现金占用周期按"下单→回款"约 28 周（W0 下单、W6 出厂、W7 到货、W12 SAT、W16 终验、W20 回款，加 8 周缓冲）：

```
年吞吐 = 1 MW × (52 ÷ 28) = 1.86 MW/年
```
复算：`52/28 = 1.857` ✔

**与盈亏平衡对照：**

| 项 | 值 |
|---|---|
| 阶段一现金约束下的年交付能力 | **1.86 MW/年** |
| F2 盈亏平衡所需容量（P=1,500） | 7.80 MW/年 |
| **达成率** | **23.8%** |

复算：`1.86/7.80 = 23.8%` ✔

**结论：阶段一 800 万元预算在结构上不可能达到盈亏平衡——即使全部执行成功，交付容量也只有 F2 盈亏平衡点的约 24%。这不是失败，而是阶段一的正确定位：阶段一买的是证据，不是利润。因此阶段一的目标必须写成证据里程碑，绝不能写成收入或台数目标。** 任何把阶段一设成"收入 X 万元"的目标，都在数学上要求突破现金约束。

### 3.4 §1.7 中"29 MW/年"情景的可达性裁决

在 P=1,200 元/kW（已高于实证上限 68%）时，F2 盈亏平衡需 29.09 MW/年。对照公开采购样本规模：

| 公开样本 | 容量 |
|---|---|
| 广东移动佛山 | 2.52 MW |
| 江苏移动南京 | 6.00 MW |
| 浙江移动框架（全部，两家分） | 15.00 MW（68% 份额 = 10.2 MW，跨约 2.25 年 ≈ 4.5 MW/年） |
| 联通中卫 DC7（EPC POD，非 CDU 裸机） | 24.00 MW |

`29.09 MW/年` 相当于**每年独家中标接近 5 个南京规模的项目，或约 6.5 倍浙江移动框架多数份额的年化量**。在无 OEM 指定、无全球服务、无历史业绩的条件下，该容量不可达。
复算：`29.09/6.00 = 4.85`；`29.09/4.5 = 6.46` ✔

### 3.5 现金安全三条底线

| # | 底线 | 公式 | 阶段一取值（1 MW 已签） |
|---|---|---|---|
| **B1 最低现金余额** | `≥ 单项目峰值占用 × 已签MW + 3个月经常性固定费用` | `91 × 1 + 320 ÷ 4 = 91 + 80 = 171 万元` | **≥ 171 万元**；建议董事会批准 **200 万元** 留 17% 缓冲 |
| **B2 最大并行项目数** | `⌊(可用营运资金 − B1缓冲) ÷ 单项目峰值占用⌋` | `⌊(160 − 0) ÷ 91⌋ = 1` | **1 个 1 MW 级项目；第二个项目必须等第一个回款到账后才可签约** |
| **B3 最长可承受回款延迟** | `(可用营运资金 − 单项目峰值占用) ÷ 每周经常性支出` | `(160 − 91) ÷ (320 ÷ 52) = 69 ÷ 6.154 = 11.2 周` | **11 周**。超过即触发现金红线 |

复算：`320/4 = 80`；`91+80 = 171`；`171×1.17 = 200`；`320/52 = 6.1538`；`(160−91)/6.1538 = 11.21` ✔

### 3.6 B3 与实测验收周期的冲突（关键风险）

| 已核验的验收/付款尾部 | 周期 |
|---|---|
| C-DAC：供货+安装+调试+测试 | 16 周 |
| 中国运营商：终验后质保起算，但终验日期未公开 | 无数据 |
| TCIL：全项目 214 天；付款延伸至带载运行 6 个月、投运满 1 年 | 30–52 周 |
| 联通中卫：以"第三方验证测试 + 最终客户验收"为完成标准 | 无数据，但结构上可长 |

**B3 = 11 周的容忍度，显著低于已核验合同中出现的验收与付款尾部（16 周至 52 周）。** 即：**按公开合同条款的常见结构，阶段一的现金结构在单个项目上就会被击穿。** 因此：

- **争取预付款不是优化项，是生存条件。** 30% 预付款可把峰值从 91 万降到 55 万元/MW，B3 从 11.2 周延长到 `(160−55)/6.154 = 17.1 周`。
- **拒绝"pay-when-paid"背靠背条款是红线。** TCIL 式"以收到最终客户付款为前提"会把回款不确定性无限延长。
- **必须把自身收款绑定到"CDU 到货 + SAT"，而不是最终客户验收或投运周年。**

复算：`0.30×120 = 36`；`91−36 = 55`；`(160−55)/6.1538 = 17.06 周` ✔

## 4. 全部公式汇总（供独立复算）

```
# 缺口二
F1 = 阶段一费用性支出总额 = 800 − 110 = 690                       （万元/年）
F2 = 稳态经常性固定费用 = 220 + 50 + 20 + 30 = 320                 （万元/年）
C_nonBOM  = 100 + 150 + 50 + 40 + 70 + 30 = 440                    （元/kW）
C_total   = BOM + C_nonBOM                                          （元/kW）
CM_int    = P_netrev − C_total                                      （元/kW）
CM_rate   = CM_int ÷ P_netrev
BE_cap    = F × 10,000 ÷ CM_int                                     （kW/年，F 单位万元）
P_floor   = C_total                                                 （零贡献价格下界）
BOM_max   = P_target − C_nonBOM                                     （给定价格下的 BOM 上限）
单位容量价格 = 项目总价 ÷ (台数 × 单台额定容量)                     （元/kW）

# 缺口三
液体负荷/柜   = 机柜 IT 功率 × HCR
覆盖柜数      = CDU 额定容量 ÷ 液体负荷每柜
单柜 IT 价值  = 服务器价值强度(美元/W) × 机柜功率(W) × 汇率
敞口          = 覆盖柜数 × 单柜 IT 价值
敞口倍数_合同 = 敞口 ÷ 合同额
敞口倍数_毛利 = 敞口 ÷ (合同额 × 毛利率)

# 缺口四
峰值现金/MW   = BOM现金 + 安装现金 + 物流现金 + 履约保证金 − 预付款
              = 65 + 15 + 5 + 0.05×合同额 − 预付比例×合同额        （万元/MW）
并行容量      = 可用营运资金 ÷ 峰值现金每MW                         （MW）
年吞吐        = 并行容量 × (52 ÷ 项目现金周期周数)                  （MW/年）
B1 最低现金   = 峰值现金每MW × 已签MW + F2 ÷ 4
B2 最大并行   = FLOOR(可用营运资金 ÷ 峰值现金每MW)
B3 延迟容忍   = (可用营运资金 − 峰值现金占用) ÷ (F2 ÷ 52)           （周）
```
