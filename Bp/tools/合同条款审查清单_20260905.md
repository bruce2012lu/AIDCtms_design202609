## 使用规则

**三级标注定义：**

| 标注 | 含义 | 处置 |
|---|---|---|
| 🔴 **红线** | 无法达成即**不接单**。这些条款决定的不是利润高低，而是单次事故是否会消灭整个业务 | 必须获得，无例外授权不得签署 |
| 🟡 **可谈判** | 影响利润与现金，但可通过定价、保险或技术手段对冲 | 未获得时须书面记录对冲方案与定价补偿 |
| 🟢 **可接受** | 行业常见，接受即可，但须知悉成本并计入报价 | 计入报价成本，无需上升 |

**审查纪律：**
1. **红线条款有 8 条。任何一条未达成，不得签署，须提交管理层专项决议。**
2. 每条填写"合同实际文本"栏，**不得只填"符合/不符合"**。要摘录原文。
3. 涉及金额的条款必须换算成"占合同额百分比"和"绝对金额"两个口径。
4. 责任类条款须同时检查**上限**和**上限的例外（carve-out）**。只看上限会严重低估敞口。
5. 保险类条款须与责任类条款**逐条对照**：合同要我方赔的，保险必须能保。不能保的部分是自留风险，须量化。

> **审查提示（1.1–1.3）：** 律所专业评论指出，业主常要求把数据丢失与网络安全加入上限例外，而承包商强烈抵制，理由是单次事件的责任可达远超项目价值与可获得保险额度。反证：C-DAC 2024 招标澄清中，供应商自拟的"责任限于合同总价 + 排除间接损失"文本被采购人**删除**，改为适用 GeM 标准责任条款。**因此本组条款必须视为需要主动争取的对象，不能假定默认可得。**

## 十、为什么这 8 条是红线（量化依据）

以 200 kW CDU 配套包为例，按已核验的国内运营商包价上限计算：

| 项 | 值 |
|---|---|
| 合同额（715 元/kW × 200 kW） | **14.30 万元** |
| 项目毛利（按曙光数创冷板液冷 10.36% 实证锚点） | **1.48 万元** |
| 单块 GPU 基板更换成本（3.5–5.0 万美元，三级来源，汇率 7.2） | **25.2–36.0 万元** |
| 单柜 IT 资产价值（Epoch AI 21.2 美元/W × 135 kW，汇率 7.2） | **2,060.6 万元** |
| 该 CDU 覆盖的 IT 资产（200 ÷ 121.5 = 1.65 柜） | **3,392 万元** |
| 行业指引转引的责任上限（合同价 10%–20%，三级） | **1.43–2.86 万元** |

**结论：**

1. **一次 50 ml 冷却液滴落造成的单块基板损坏（25.2–36.0 万元），等于合同额的 1.76–2.52 倍、项目毛利的 17.0–24.3 倍。** 在最小可想象的事故中，供应商已赔掉 17–24 个同规模项目的全部毛利。
2. **单柜全损（2,060.6 万元）等于合同额的 144 倍、项目毛利的 1,391 倍，且是阶段一全部预算（800 万元）的 2.58 倍。** 即一次事故可以消灭整个业务。
3. **行业惯例的"合同价 10%–20% 责任上限"只有 1.43–2.86 万元，仅为单块基板成本的 4%–11%，连一块基板都赔不起。** 因此客户的理性诉求必然是不封顶或设超级上限——这正是谈判会破裂的地方，也正是这些条款必须成为红线的原因。
4. **责任封顶不是谈判技巧，而是业务成立的前提条件。** 若无法取得 R1–R6，该项目的数学期望是负的，无论定价多高。

复算：`715×200÷10,000 = 14.30`；`14.30×10.36% = 1.4815`；`35,000×7.2÷10,000 = 25.2`；`50,000×7.2÷10,000 = 36.0`；`25.2÷1.4815 = 17.01`；`36.0÷1.4815 = 24.30`；`21.2×135,000×7.2÷10,000 = 2,060.64`；`2,060.64÷14.30 = 144.10`；`2,060.64÷1.4815 = 1,390.93`；`2,060.64÷800 = 2.576`；`200÷121.5 = 1.6461`；`1.6461×2,060.64 = 3,392.0`
