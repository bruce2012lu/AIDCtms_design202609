## 致供应商

我方正在开发面向数据中心的冷板式液冷冷量分配单元（CDU），容量档为 **100 / 200 / 300 / 450 kW** 四档。本次询价目的是取得**同工况、同边界、可横向比较**的书面报价，用于产品定义与成本结构核算。

## 第一部分｜统一工况说明（所有报价必须基于本工况）

> 除特别说明，以下工况适用于全部四个容量档。选型如需偏离，请在"偏离说明"栏逐项列出。

### 1.1 热工与水力

| 项目 | 要求 |
|---|---|
| 一次侧（设施侧 FWS）供/回液温度 | **37 / 45 ℃** |
| 二次侧（技术侧 TCS）供/回液温度 | **40 / 50 ℃** |
| 接近温差 ATD（一次侧进液与二次侧出液之差） | **≤ 5 K**，请注明选型实际值 |
| 二次侧最高工作压力 | **3.5 bar(g)** |
| 二次侧设计压力 | **≥ 6 bar(g)**，耐压试验 ≥ 1.5 倍设计压力 |
| 二次侧工质 | **乙二醇水溶液 20%–25%（EG20–25）**；请同时报 **丙二醇 25%（PG25）** 选型差异 |
| 一次侧工质 | 冷却水（可含 EG，视项目） |
| 额定热负荷 | 按各容量档铭牌值，在上述工况下满足 |
| 二次侧额定流量 | 由供应商按 ΔT=10 K 选型后填写 |
| 二次侧额定扬程／可用压差 | 请给出 Q–ΔP 曲线，并标注额定工作点 |
| 过滤 | 二次侧全流量过滤，过滤精度请建议（我方倾向 ≤ 50 μm），含压差监测 |
| 水质 | 参照 OCP《Base Specification for Single Phase Water-Based Cold Plate Coolants》v1.3（2026-08-06 生效）；请注明兼容性 |

### 1.2 冗余与可维护性

| 项目 | 要求 |
|---|---|
| 泵冗余 | **N+1**（两台泵，单台可承担 100% 额定负荷）；请另报 **2N** 选项 |
| 泵切换 | 自动切换，切换过程二次侧不得断流；请给出切换时间 |
| 控制冗余 | 请说明是否支持控制器冗余，并另报价 |
| 电源 | 双路电源输入 + 自动切换（ATS）；请另报单路选项 |
| 维护方式 | 泵、过滤器、传感器要求**不停机可维护**（热插拔或旁通隔离）；请说明实现方式 |
| 故障态能力 | 请给出**单泵故障状态下**的额定能力（不得只给正常态） |

| 遥测点位 | 二次侧供/回液温度、流量、进出口压力、压差、泵转速/电流/运行时长、过滤器压差、液位、电导率、漏液报警、阀位、故障与冗余状态 |
| 报警与联锁 | 高/低液位、高/低压、超温、流量低、漏液、泵故障、通信中断；漏液报警须支持**联动切断** |
| 传感器校准 | 请说明出厂校准与现场调试校准要求，并提供校准证书 |

### 1.4 结构与接口

| 项目 | 要求 |
|---|---|
| 形式 | 落地式机柜（in-row 或 end-of-row），请注明外形尺寸与重量 |
